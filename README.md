# 치지직 Caps Lock 이모티콘

치지직 채팅 단축키·검색·채널 목록·플레이어 도구, 치지직·숲 자유 배치 채팅과 목록 미리보기, 유튜브·넥슨 라이브의 큰 영상과 옆 채팅, 모든 사이트의 영상 배속·프레임 이동을 제공하는 Chrome/Edge 확장 프로그램입니다.

## 0.10.21 편의 도구

따라잡기 여유를 **2초 / 1.5초 / 1초** 세 칸 스위치 중 하나로 선택합니다. 기본값과 기존 안정/최소 지연 설정은 **2초**로 적용합니다. 선택한 초 값은 오래 재생하거나 버퍼링이 생겨도 자동으로 줄이거나 늘리지 않습니다. 자동 따라잡기를 꺼 둔 설정은 유지합니다. 이 수치는 **최신으로 내려받은 버퍼와의 여유**이며 전체 방송 지연의 측정값은 아닙니다.

자동 따라잡기는 **재생 위치를 건너뛰지 않고 1.03 / 1.08 / 1.15배속으로만** 밀린 영상을 따라잡습니다. 목표에 가까워지면 감속하고 1배속으로 돌아옵니다. 큰 지연도 자동으로 순간 이동하지 않습니다. **지금 따라잡기**를 직접 누를 때만 내려받은 버퍼 안에서 선택한 여유를 남기는 위치로 이동합니다. 실제 버퍼 부족·일시정지·수동 배속 제외는 유지하며 30초 자동 중단은 없습니다.

각 옵션에 마우스를 올리면 **기다림 없이 바로** 여유와 끊김 가능성을 설명하는 안내가 뜹니다. 키보드로 선택할 때도 안내가 표시되며, 플레이어와 확장 설정의 선택값은 동기화됩니다. 초록색 바가 선택한 칸으로 미끄러지는 애니메이션은 유지합니다.

**확장을 다시 로드하고 열린 치지직 탭도 새로고침하세요.** 모형에서 자동 위치 이동이 없고 배속으로 목표 여유에 도달하는지 확인했으며 실제 사용자 방송의 끊김 개선은 확인 전입니다.

## 0.10.20 편의 도구

따라잡기의 **30초 자동 중단을 완전히 제거**했습니다. 재생 위치 변경·타임바 조작·되감기 키·외부 배속 변경에 별도 30초 타이머를 걸지 않습니다. 자동 따라잡기가 켜져 있으면 직접 되감은 뒤에도 밀린 영상을 다시 당깁니다. 늦은 위치를 계속 보고 싶으면 자동 따라잡기를 끄면 됩니다. 사용자 지정 배속은 유지하며 일반 1배속으로 돌아오면 별도 30초 대기 없이 보정을 재개합니다. 안정 우선/최소 지연, 실제 버퍼 부족·일시정지·탐색 진행 중 처리와 짧은 중복 이동 제한은 유지합니다.

**확장을 다시 로드하고 열린 치지직 탭도 새로고침하세요.**

## 0.10.19 편의 도구

안정 우선도 밀린 영상을 계속 당기도록 변경했습니다. 준비된 영상이 있으면 시작부터 보정하며, 데이터·재생 이벤트에서 지연을 검사합니다. 시작·광고 종료 5초 대기, 버퍼링 뒤 고정 15초 대기와 이동 간격 20초를 없앴습니다. 안정 우선은 **0.75~1.5초**, 최소 지연은 **0.35~0.75초** 범위에서 버퍼 여유를 유지하며 반복해서 끊겨도 6초까지 늘리지 않습니다. 큰 지연은 내려받은 버퍼 안에서 이동하고, 작은 차이는 방식별 배속으로 줄입니다. 연속 이동 제한은 안정 우선 3초, 최소 지연 2초이며 미디어 이벤트에서도 이 제한을 지킵니다. 버퍼가 실제로 부족하면 기다리되 재생 가능 신호가 오면 즉시 재검사합니다.

**위치 이동 감지 · 자동 따라잡기만 30초 대기**가 자동 이동에도 걸리던 처리를 제거했습니다. `seeking` 이벤트만으로 사용자 되감기를 추측하지 않습니다. 직접 타임바를 누르거나 되감기 키를 입력했을 때만 30초간 선택 위치를 보호하며, **지금 따라잡기**는 이 보호도 즉시 해제합니다. 방식 스위치의 좌우 방향키는 되감기로 처리하지 않습니다. 두 방식의 초록색 좌우 스위치는 유지합니다.

표시된 버퍼 여유는 전체 방송 지연의 측정값이 아닙니다. 모형에서 자동 이동 오인과 반복 버퍼링 뒤 보정 누락을 재현·검증했으며, 실제 사용자 방송에서 끊김과 체감 지연이 개선됐는지는 확인 전입니다. **확장을 다시 로드하고 열린 치지직 탭도 새로고침하세요.**

## 0.10.18 편의 도구

따라잡기 방식 선택을 드롭다운 대신 **안정 우선 | 최소 지연** 좌우 스위치로 바꿨습니다. 선택한 쪽으로 초록색 배경이 0.22초 동안 미끄러지며, 아래 **지금 따라잡기** 버튼과 같은 색·둥근 모서리를 사용합니다. 플레이어와 확장 팝업 모두 동일한 방식으로 표시하고 기존 선택값을 유지합니다. 두 방식은 동시에 켜지지 않습니다. 키보드 Tab·좌우 방향키로도 조작할 수 있으며 자동 따라잡기를 끄면 스위치도 비활성화합니다.

방식 선택 시 Windows 기본 드롭다운 팝업을 띄우는 경로를 제거했습니다. 사용자가 보고한 실제 커서 이동의 원인은 재현하지 못했으므로 해결됐다고 단정하지 않습니다. **확장을 다시 로드하고 열린 치지직 탭도 새로고침하세요.**

## 0.10.17 편의 도구

**따라잡기 → 방식**에서 아래 둘 중 하나만 선택합니다. 확장 팝업에도 같은 설정이 있으며 서로 동기화됩니다.

- **안정 우선 (이전 방식)** — 기본값입니다. 0.10.15의 버퍼 여유·완만한 배속·회복 대기를 복원합니다. 최신 버퍼의 1.5초 전에서 시작하고 안정 재생 시 최소 0.75초까지 줄입니다. 시작 5초·버퍼링 후 15초 대기, 자동 이동 간격 20초, 작은 차이는 1.03~1.08배속입니다.
- **최소 지연 (끊길 수 있음)** — 0.10.16의 적극적인 보정입니다. 최신 버퍼의 0.35초 전을 목표로 데이터·재생 이벤트에서 즉시 보정하며 회선 상태에 따라 중간에 끊길 수 있습니다.

기존 설정에 방식 선택이 없으면 안정 우선으로 적용합니다. 자동 따라잡기를 꺼 둔 설정은 그대로 유지합니다. 방식 변경은 열린 플레이어에 바로 적용하며, 이전 방식의 자동 배속·회복 상태를 정리하고 선택한 방식으로 전환합니다. 켜짐의 초록색 표시는 두 방식 모두 동일합니다. **확장을 다시 로드하고 열린 치지직 탭도 새로고침하세요.** 실제 사용자 환경에서 끊김이 줄었는지는 아직 확인하지 못했습니다.

## 0.10.16 편의 도구

자동 따라잡기가 켜져 있으면 플레이어의 **따라잡기 글자와 아이콘이 초록색**으로 표시됩니다. 꺼져 있으면 흰색 35% 반투명입니다. 설정 패널을 열지 않아도 상태를 확인할 수 있습니다.

내 플레이어가 내려받은 최신 영상보다 뒤처지는 시간을 줄였습니다. 처음부터 최신 버퍼의 **0.35초 전**을 목표로 하고, 시작 시 고정 5초 대기를 없앴습니다. 데이터 수신·재생 이벤트에서 바로 보정하며 작은 차이는 1.05~1.15배속, 목표보다 1초 넘게 밀리면 버퍼 안에서 이동합니다. 자동 이동 제한은 20초에서 2초로 줄였습니다. 끊김 뒤에는 버퍼 여유를 늘리되 재생 가능 신호가 오면 즉시 재개하고, 신호가 없으면 2초 뒤 다시 검사합니다. 광고 종료 대기는 5초에서 0.75초로 줄였습니다. 수동 되감기·배속·일시정지 보호는 유지합니다.

0.35초는 **최신 다운로드 버퍼와의 목표 거리**이며 스트리머 송출부터 내 화면까지의 전체 지연이 아닙니다. 네트워크가 불안정하면 더 자주 끊길 수 있어 실제 버퍼링 시 여유를 자동으로 늘립니다. 채팅 Enter 전송 경로에는 확장이 추가하는 대기가 없으며, 채팅을 자동 전송하지 않습니다. 스트리머의 채팅 오버레이·서버·방송 송출 지연은 바꾸지 않습니다. 모형 검사와 unpacked 확장 로드를 확인했으며 실제 로그인 채팅 및 방송 속 채팅 도착 시간은 측정하지 않았습니다. **확장을 다시 로드하고 열려 있는 치지직 탭도 새로고침해야 적용됩니다.**

## 0.10.15 편의 도구

F가 광고 재생 중이거나 극장모드 버튼이 일시적으로 숨겨진 동안 치지직의 기본 전체화면 동작으로 넘어가던 경로를 막았습니다. 광고 중에도 극장모드를 전환하며, 버튼이 준비되지 않았으면 전체화면으로 넘어가지 않고 기다립니다.

생방송 광고 중 본방송이 계속 우측 상단에 작게 뜨던 배치도 수정했습니다. 실제 치지직 CSS의 고정 크기 `miniplayer` 규칙을 반영해 본방송 바깥 영역(`#live_player_layout`)까지 전체 크기로 복원하고, 광고 컨테이너만 작게 유지합니다. 광고 컨테이너 크기를 강제하는 네이티브 CSS보다 우선하도록 적용합니다. 광고 종료·설정 해제·채널 이동 시 확장의 배치를 해제합니다. 공개 다시보기에서 F 왕복 전환을 확인했고, 광고 배치는 최신 공개 CSS를 반영한 모형에서 검증했습니다. 사용자 웨일의 실제 로그인 생방송 광고는 아직 확인하지 못했습니다. **확장을 다시 로드하고 열려 있는 생방송 탭도 새로고침해야 적용됩니다.**

광고 시작 직후 잠깐 소리가 나던 경로를 수정했습니다. 광고 음소거 처리를 문서 시작부터 준비하고, 1초 주기 검사 외에 광고 소스·DOM·미디어 이벤트에서도 즉시 적용합니다. 실제 SDK 광고 소스는 데이터 로딩과 광고 상태 표시 전부터 미리 음소거하며 빈 자동재생 검사 영상은 제외합니다. 광고 종료 후 본편 음량 복원은 유지합니다. 다시보기에서 광고 중에만 본편이 멈추는 것은 확장 없는 공개 페이지에서도 확인한 치지직 기본 동작입니다.

치지직·숲에서 **F**로 기본 극장모드를 전환합니다. 치지직은 **넓은 화면**, 숲은 **스크린모드** 버튼을 각각 실행하며, 다시 누르면 원래 화면으로 돌아옵니다. **Esc**로도 해제하며, 채팅·검색창·일반 버튼에 포커스가 있어도 작동합니다. 일반 화면의 Esc는 가로채지 않고 실제 전체화면에서는 브라우저의 기본 해제를 유지합니다. 사이트의 기본 F 전체화면과 중복되지 않도록 keydown·keyup을 함께 처리합니다. F는 입력창·채팅·조합키·한글 조합 중에는 가로채지 않고 길게 눌러도 반복 전환하지 않습니다.

숲 **스페이스**는 정상 타임머신 일시정지·재생이 동작하면 그대로 두고, 상태 변화가 없으면 기본 **정지/재생** 버튼을 사용합니다. 정지로 영상이 제거돼도 스페이스를 다시 누르면 기본 재생 버튼으로 재접속합니다. 타임머신 전환이 늦더라도 기본 버튼 상태가 바뀌었으면 정지로 덮어쓰지 않습니다. 확장이 타임머신 일시정지 버튼을 직접 누르거나 이용 조건을 변경하지 않습니다.

스페이스 입력이 정상 수신돼도 **숨겨진 모달의 DOM이 남아 있으면 재생 복구를 차단하던 오류**를 수정했습니다. 표시 크기·화면 위치·숨김·투명도·부모 상태를 확인해 실제 보이는 모달만 키를 소유하도록 합니다. 사용자 진단에서 확인한 `Space 모달로 판단 (↓53/↑53)` 경로를 기준으로 수정했으며, 효과 없던 광고 판정 변경과 즉시 실행 변경은 되돌렸습니다.

**확장을 다시 로드한 뒤에는 이미 열려 있던 치지직·유튜브·숲 등 영상 탭도 각각 새로고침해야 합니다.** 확장 재로드로 연결이 끊긴 기존 유튜브 탭에서 `,`·`.`가 멈춘 경우에도 해당 탭 새로고침으로 다시 연결합니다.

실제 탭에서 원인을 확인할 수 있도록 팝업 하단에 **Space 처리 결과·수신 횟수·현재 플레이어 판정**을 표시합니다. 입력창 내용·방송 주소는 포함하지 않고 페이지 메모리에만 유지합니다. 확장·페이지 버전 표시가 0.10.6에 남아 잘못 재로드를 안내하던 표시도 맞췄습니다. 사용자 웨일에서의 최종 해결 여부는 아직 확인하지 못했습니다.

`ad-skip.js`의 `ChzzkAdDom is not defined` 오류를 수정했습니다. 문서 시작의 광고 추적을 유지하면서, 플레이어 도구가 실행되기 직전에도 같은 추적 객체의 초기화를 보장합니다. 객체가 아직 없으면 기다렸다가 준비된 뒤 스킵·음소거를 재개합니다. 정상 초기화에서는 기존 객체와 제거된 광고 추적을 유지합니다. **확장을 다시 로드한 뒤 열려 있는 치지직 탭도 새로고침해야 합니다.**

AdGuard의 한국어 필터가 다시보기 광고 영역을 **문서에서 제거한 뒤에도 광고 SDK가 소리만 재생하는 경로**를 수정했습니다. 문서 시작부터 광고 영역의 제거를 추적해 해당 광고에도 음소거·배속과 활성화된 기본 스킵 버튼 처리를 적용합니다. 제거된 광고를 다시 화면에 붙이지 않으며, 다른 페이지로 이동하면 남은 광고 재생을 정리합니다. 광고만 음소거하면서 본편 소리는 유지합니다. 실제 공개 다시보기 광고에 설치된 AdGuard의 제거 규칙을 적용해 기존 코드의 소리 잔류와 수정 후 음소거·본편 복귀를 비교했습니다. **확장을 다시 로드한 뒤 기존 다시보기 탭도 새로고침해야 합니다.**

한글 조합 중에 Caps Lock 단축키로 문자나 이모티콘을 넣은 뒤 전송하면 작성창에 내용이 남을 수 있던 경로를 수정했습니다. 치지직이 이미 받은 조합 시작에 대응하는 종료 이벤트는 누출 문자를 제거한 뒤 전달해, 치지직 자체 전송 처리가 작성창을 정상 초기화하도록 합니다. 전송 실패를 추측해 초안을 지우거나 추가 전송하지 않습니다. 로컬 조합·전송 모형에서 수정 전 잔류와 수정 후 초기화를 확인했으며 실제 로그인 채팅 전송은 사용자가 확인해야 합니다.

채널의 라이브·오프라인 채팅 바로가기는 기본 메뉴와 같은 글꼴·크기·색상·간격을 사용합니다. 별도 화살표 아이콘과 라이브 강조색을 제거했습니다.

스트리머 채널 메뉴의 **정보 바로 뒤**에 **라이브 / 오프라인(채팅)** 바로가기를 추가했습니다. 방송 중이면 라이브, 방송이 꺼져 있으면 오프라인(채팅)으로 표시하고 해당 채널의 기본 라이브·채팅 페이지를 엽니다. 홈뿐 아니라 동영상·클립·재생목록·커뮤니티·정보에서도 표시합니다. 상태를 확인하지 못하면 **라이브·채팅**으로 표시하며 이동은 가능합니다. 공개 채널 정보의 기존 30초 캐시를 함께 사용하고 숨긴 탭에서는 새로 조회하지 않습니다. Ctrl·Shift·가운데 클릭의 기본 새 탭 동작도 유지합니다.

기본 켜짐이며 팝업의 **채널 메뉴의 라이브 · 오프라인(채팅) 바로가기**에서 끌 수 있습니다. 치즈 플래터가 같은 메뉴에 바로가기를 표시 중이면 확장 쪽 버튼을 숨겨 중복을 피합니다. 실제 채팅 이용에는 치지직의 로그인·채팅 권한 조건이 그대로 적용됩니다.

치지직·숲에서 **F11이 사이트의 키 이벤트 취소에 막히지 않도록 브라우저 기본 동작을 보호**합니다. 스페이스·M(치지직 K 포함)은 사이트가 정상 처리하면 그대로 두고, 키를 뗀 뒤에도 재생·음소거 상태가 바뀌지 않았을 때만 원래 플레이어 버튼으로 보조 실행합니다. 한글 IME가 M을 `Process`로 보고해도 물리 키 코드로 인식합니다. 입력창·채팅·일반 버튼·수정키 조합과 광고·표시 중인 모달에서는 보조 실행하지 않습니다. 팝업의 **치지직·숲 F/Esc 극장모드 · F11 보호 · 재생·정지·음소거 복구**에서 끌 수 있습니다.

숲의 공개 LiveView 코드에서 영상·컨트롤의 모든 keydown/keyup을 취소하는 경로를 확인했고, 동일한 취소 처리와 전체 키 전파 차단을 로컬에서 모사해 검증했습니다. 현재 사용자 웨일 탭에서 발생한 모든 단축키 차단의 원인과 실제 방송에서의 재발 여부는 확인하지 못했습니다. 확장을 다시 로드한 뒤 숲·치지직 탭도 새로고침해야 적용됩니다.

치지직 다시보기의 **넓은 화면**에서는 오른쪽 페이지 스크롤바를 숨깁니다. F11 전체화면에서도 적용되며 휠 스크롤과 채팅 목록 내부 스크롤은 유지합니다. 일반 화면으로 돌아오면 스크롤바를 복원합니다.

Caps Lock 입력은 네이티브 작성 상태와 화면의 이모티콘을 함께 확인해 최대 10개를 지킵니다. 중복 keydown을 억제하고 삭제·전송 전후 IME 감시가 이전 문장을 복원하지 않도록 보완했습니다. 문자열이 기존 문장과 합쳐 이모티콘 코드가 되는 경우도 제한합니다. 이미 10개를 초과한 메시지는 Enter와 전송 버튼에서 막고 안내합니다.

치지직 다시보기의 **라이브 채팅 다시보기**도 일반 화면에서 폭을 조절하고 넓은 화면에서 이동·크기·투명도를 조절할 수 있습니다. 유튜브는 원래 채팅 iframe 내부의 최소 폭을 해제하고 좁은 폭에서 메시지가 줄바꿈되게 합니다.

배속은 키를 누른 즉시 반영하고 iframe 응답을 기다리며 명령을 쌓지 않습니다. 안내는 브라우저 화면 왼쪽 위 16px에 표시합니다. 영상이 없어도 미리 조절하며 나중에 생긴 영상에 적용합니다.

라이브 광고를 작게 띄울 때 본방의 상위 컨테이너도 전체 크기로 맞춥니다. 본방이 멈추면 광고는 원래 크기로 돌아갑니다. 다시보기는 실제 SDK 광고가 재생 상태인데 가려진 경우 해당 영상 경로와 기본 컨트롤을 표시합니다. 차단된 광고 파일을 복구하거나 AdGuard 설정을 변경하지는 않습니다. 실제 로그인 채팅 및 사용자의 AdGuard 조합은 별도 확인이 필요합니다.

라이브 시청 화면뿐 아니라 **스트리머 채널 메인 페이지**에서도 팔로우/팔로잉 왼쪽에 **보관** 버튼을 표시합니다. 메인에서 바로 보관·해제하고, 라이브 화면으로 이동해도 같은 저장 상태를 유지합니다. 채널 메인의 이름과 프로필 사진을 읽으며 추가 조회 타이머는 만들지 않습니다.

따라잡기 버튼은 치지직 기본 컨트롤의 표시·숨김 상태를 함께 따릅니다. 컨트롤이 보일 때 자동 따라잡기가 켜져 있으면 초록색, 꺼져 있으면 흰색 35% 반투명으로 표시하고 기본 컨트롤이 숨겨지면 버튼도 완전히 숨깁니다.

따라잡기 설정 팝업은 바깥 화면을 클릭하면 닫힙니다. 팝업 안의 설정·버튼은 계속 조작할 수 있고 따라잡기 버튼으로 여닫기도 유지합니다.

치지직에서 직접 올린 썸네일을 쓰고 썸네일 영역 자체가 링크인 카드를 인식하지 못하던 문제를 수정했습니다. 해당 이미지·LIVE 배지 위에서도 우클릭 미리보기를 시작하며 제목·스트리머명은 원래 메뉴를 유지합니다.

유튜브 큰 화면에서 내부 영상의 고정 픽셀 크기가 남아 작게 표시되는 경로를 수정했습니다. 안쪽 플레이어·영상도 영역 크기에 맞추고 비율을 유지하며, 채팅 폭 변경을 기본 플레이어에도 알립니다. 배속 안내는 최대 36px에서 24px로 줄이고 상자 여백도 줄였습니다.

### 유튜브 큰 극장 화면과 오른쪽 채팅

사용자가 제공한 **YT Fake Fullscreen 4.0**을 통합했습니다. 영상 페이지에서 **F**는 화면 높이를 채우는 큰 극장 모드, **T**는 유튜브의 실제 전체화면입니다. **Esc**는 큰 극장 모드를 해제하며, 검색창과 원래 채팅 iframe의 입력창에서도 작동하고 작성 내용을 유지합니다. 마우스로 전체화면 버튼을 누르면 큰 극장 모드를 전환하며, 실제 전체화면에서의 종료 버튼은 그대로 작동합니다. T의 버튼 클릭이 다시 극장 모드로 가로채지지 않도록 구분합니다. F/T는 검색·채팅·편집 영역과 조합 중인 키는 가로채지 않고 키를 길게 눌러도 반복 전환하지 않습니다.

큰 극장 모드에 펼친 라이브 채팅이 있으면 **영상 왼쪽 + 채팅 오른쪽**으로 화면 높이를 채웁니다. 경계를 드래그하거나 방향키로 채팅 폭을 조절하고 Home·두 번 클릭으로 360px에 돌아갑니다. 고정 240px 최소 폭은 없으며, 작은 폭도 이 브라우저에 저장합니다. 채팅 iframe과 문서는 원래 자리에 두고 내부 메시지의 최소 폭·줄바꿈만 조절해 작성 중 내용을 보존합니다. 원래 접힌 채팅이나 사용할 수 없는 채팅을 강제로 열지 않습니다.

위로 스크롤하면 상단바를 2초 보여 주고 상단바에 마우스가 있으면 유지합니다. 기능은 팝업의 **유튜브 큰 극장 화면 · F/T/Esc 전환 · 옆 채팅**에서 끌 수 있습니다. 기존 **YT Fake Fullscreen** 사용자 스크립트가 감지되면 확장 쪽은 대기하므로, 대체해서 쓰려면 해당 스크립트를 끄고 유튜브 탭을 새로고침하세요.

### 넥슨 라이브 큰 영상과 옆 채팅

사용자가 제공한 **넥슨 라이브 · 영상 크게 + 옆 채팅 1.0.0**을 통합했습니다. 영상과 원래 채팅이 있는 페이지에서 **영상 왼쪽 + 채팅 오른쪽** 배치를 사용합니다. 경계 드래그·방향키·Home·두 번 클릭과 폭 저장을 지원합니다. **Alt+Shift+M** 또는 **원래 화면 / 크게 보기**로 전환하고, **F / 화면 채우기**로 영상과 채팅을 함께 전체화면에 표시합니다.

첨부 코드의 기존 화면 구조와 공개 다시보기에서 확인한 새 플레이어·채팅 구조를 지원합니다. 새 확장 설정이 없으면 기존 사이트 로컬 저장소의 `nlf.enabled`·`nlf.width` 값을 참조하며, 이후 변경은 확장 로컬 저장소에 저장합니다. 원래 저장값은 삭제하지 않습니다. 팝업에서 별도로 끌 수 있고 기존 넥슨 배치 사용자 스크립트가 실행 중이면 확장 쪽은 대기합니다.

### 치지직 생방송 광고 후 소리 복원

광고 종료 시 한 번만 복원한 뒤 지연된 음소거·음량 0 변경이나 본방 요소 교체가 일어나면 복원하지 못하던 경로를 보완했습니다. 종료 후 5초 동안 광고 전 음소거·음량을 복원하며, 원래 음소거한 사용자는 계속 음소거로 유지합니다. 이 기간에 사용자가 페이지의 음량·음소거 조작 또는 M 키를 사용하면 복원을 중단합니다. 다른 채널로 이동하거나 광고 음소거 기능을 끄면 이전 복원 상태도 해제합니다. 실제 사용자 환경에서의 원인은 아직 확정하지 않았으며 지연 변경과 요소 교체는 로컬에서 모사해 확인했습니다.

### 치지직·숲 자유 배치 채팅

사용자가 제공한 **SOOP·치지직 자유 배치 채팅 1.4.0**의 기능을 확장에 통합했습니다. 치지직 생방송·다시보기의 **넓은 화면**, 숲 **스크린모드**에서 기본 채팅을 영상 위에 띄웁니다. 치지직 일반 화면에서도 채팅 왼쪽 경계로 폭을 조절합니다.

- **채팅 이동** 부분을 드래그해 위치를 옮기고, 가장자리·모서리의 여덟 손잡이로 크기를 조절합니다. **투명도** 버튼에서 배경 농도를 바꿉니다.
- **원래 배치** 또는 화면 왼쪽 아래의 **채팅 겹치기** 버튼, `Alt+Shift+C`로 겹치기를 전환합니다. **치지직·숲 모두 겹치기를 끈 오른쪽 배치에서 채팅 왼쪽 경계를 드래그해 폭을 조절**할 수 있습니다. 치지직은 일반 화면과 넓은 화면에 적용하고, 숲은 스크린모드에 적용합니다.
- 두 사이트의 겹친 채팅과 오른쪽 채팅에 있던 **240px 최소 폭 제한을 제거**했습니다. 영상에 500px를 강제로 남기던 폭 제한도 제거했습니다. 실제 화면 안에서 조절하며 완전히 사라지지 않도록 1px는 유지합니다. 저장값이나 화면별 배치를 불러올 때도 작은 폭을 유지합니다.
- 위치·크기·오른쪽 채팅 폭은 화면 해상도와 배율별로 저장합니다. 처음 보는 화면에서는 크기를 비례 조정하고 이전 화면으로 돌아오면 해당 배치를 복원합니다. 투명도와 겹치기 여부도 저장합니다. 치지직과 숲의 설정은 별개입니다.
- 원래 채팅 DOM과 입력창을 이동하거나 다시 만들지 않습니다. 채팅 내용이나 메시지를 복사·저장·전송하지 않습니다.
- 팝업의 **자유 배치 채팅**은 기본 켜짐이며 끄면 스타일·손잡이·단축키를 정리합니다. 일반 화면이나 접힌 채팅에는 겹치기를 적용하지 않습니다.
- 첨부 스크립트의 `sfc-style`이 감지되면 확장 쪽 자유 배치는 대기해 중복 적용을 피합니다. 확장으로 대체하려면 **해당 템퍼몽키 스크립트만 끄고 탭을 새로고침**하세요. 확장이 템퍼몽키 설정을 변경하지 않습니다. 템퍼몽키 전용 저장소의 기존 배치값은 자동 이전되지 않으므로 확장에서 다시 배치해야 합니다.

### 미리보기 실패 안내와 복구

숲의 일반 `STATUS_ERROR` 이벤트와 치지직의 요청·파싱 실패를 미지원 방송이나 재생 제한으로 단정하던 문구를 제거했습니다. 해당 신호만으로 실패 원인을 구분할 수 없기 때문입니다. 실패하면 기존 연결을 정리한 뒤 최대 두 번 다시 불러오고, 계속 실패하면 **미리보기 다시 시도** 버튼을 표시합니다. 닫기·마우스 이탈·탭 숨김에서는 예약된 재시도도 취소합니다. 이전 플레이어의 늦은 오류가 새 미리보기에 반영되지 않도록 요청을 구분합니다. 실제 환경에서 첫 요청이 간헐적으로 실패하는 원인은 아직 확인하지 못했습니다.

### 아이콘의 현재 배속

재생·편의 기능을 나타내는 새 민트색 아이콘을 사용합니다. 브라우저 툴바에 확장을 고정하면 현재 탭의 실제 재생 배속을 아이콘 위 숫자(`1`, `1.5`, `2` 등)로 볼 수 있습니다. 사이트에서 직접 바꾼 배속과 자동 따라잡기의 `1.03`·`1.08`도 표시하며, 아이콘에 마우스를 올리면 배속을 설명합니다. 여러 영상·iframe 중에서는 큰 본방 영상을 우선하고 광고 전용 영상은 제외합니다. 영상 없이 오디오만 있으면 오디오 배속을 표시하고, 대상 미디어가 없으면 숫자를 숨깁니다. 배속 표시는 탭마다 독립적이며 새 권한이나 외부 통신은 추가하지 않습니다.

### 팔로잉 목록과 보관 채널

- 채널 행에 마우스를 올리면 둥근 별 아이콘이 나타납니다. 빈 별을 누르면 **즐겨찾기**로 고정하고, 채워진 별을 누르면 해제합니다. 평소에는 별을 숨기며 키보드로 접근할 때도 표시합니다. 즐겨찾기는 위에 모이고 일반 채널과 가로줄로 구분됩니다.
- 즐겨찾기 그룹 아래는 **팔로잉 LIVE → 보관 LIVE → 팔로잉 오프라인 → 보관 오프라인** 순서입니다. 보관 채널의 방송 상태를 다시 읽으면 표시 순서도 갱신합니다.
- **팔로잉 방송 상태 30초마다 갱신**은 기본 켜짐입니다. 화면이 보이는 동안 기본 목록의 갱신 버튼을 통해 방송 시작·종료를 다시 확인합니다. 숨겨진 탭은 갱신하지 않으며 팝업에서 끌 수 있습니다. 서버 반영 지연까지 없애지는 못합니다.
- 목록 제목 옆 **순서**를 누르면 드래그 손잡이와 위·아래 버튼으로 순서를 바꿀 수 있습니다. 같은 우선순위 구역 안에서 직접 정렬하고 이 브라우저에 저장합니다.
- **팔로잉 채널 목록 상시 펼치기**는 기본 켜짐입니다. 접힌 목록과 더보기를 펼치며 팝업의 **검색 · 채널 목록 · 플레이어 설정**에서 끌 수 있습니다.
- 팔로우하지 않고 저장하던 기존 즐겨찾기는 **보관 채널**로 이름을 바꿨습니다. 라이브 시청 화면과 스트리머 채널 메인의 **팔로우/팔로잉 왼쪽 보관 버튼**으로 추가·해제합니다. 기존 저장 목록은 그대로 유지합니다.
- 보관 채널도 같은 사이드바 목록에 나타나며 **보관** 표시로 구별합니다. 이미 팔로우한 채널은 중복 행을 만들지 않고 표시만 붙입니다. 기본 팔로잉 영역이 없으면 사이드바에 보관 목록을 표시합니다. 보관은 네이버 팔로우 상태를 바꾸지 않습니다.
- 보관 LIVE에는 카테고리·공개 시청자 수를 표시합니다. 화면이 보이는 동안 공개 정보를 30초간 재사용하며 갱신합니다. 방송자가 시청자 수를 숨기면 숫자는 표시하지 않습니다.
- 사이드바의 팔로잉·보관 LIVE에 마우스를 0.3초 올리면 오른쪽 미리보기에서 소리와 함께 재생합니다. 플레이어 음량은 100%이며 화면을 벗어나거나 Esc·닫기로 종료합니다. 별·정렬 버튼에 마우스를 올리는 동작은 재생을 시작하지 않습니다. 팝업에서 사이드바 소리 미리보기를 별도로 끌 수 있습니다.
- 팔로잉·보관 모두 같은 커스텀 플레이어로 재생합니다. hover 대기 시간부터 기본 큰 사진 툴팁을 숨기며, 기존 툴팁 안에 영상을 넣지 않습니다. 늦게 나타난 치즈 플래터 미리보기도 숨기고 재생 시도를 일시 정지합니다. 직접 고정한 외부 미리보기는 유지합니다. 종료하거나 기능을 끄면 기본 툴팁 표시를 복원합니다.
- HLS 미리보기는 작은 창 크기로 화질을 제한하지 않고 제공되는 최고 해상도로 첫 영상을 요청합니다. 이후에는 네트워크 상태에 따라 자동 조절됩니다. 서버가 낮은 화질만 제공하는 경우에는 그 이상으로 올릴 수 없습니다.
- 브라우저가 소리 자동재생을 차단하면 미리보기의 **소리 켜고 재생** 버튼을 한 번 눌러 시작합니다. 소리를 숨겨 재생됐다고 표시하지 않습니다.
- 보관 채널을 클릭하면 새로고침 없이 사이트 내에서 방송으로 이동합니다. 이동할 때 미리보기 소리는 종료합니다. Ctrl/⌘·Shift·가운데 클릭의 기본 새 탭 동작은 유지합니다.
- 왼쪽 아래 고정 패널을 제거했습니다. **자동 따라잡기 설정·지금 따라잡기**는 라이브 플레이어의 **가위 왼쪽 따라잡기 버튼** 안에 있습니다.
- 따라잡기 버튼은 기본 컨트롤이 표시된 동안 자동 따라잡기 켜짐이면 초록색·불투명, 꺼짐이면 흰색 35% 반투명으로 표시합니다. 기본 컨트롤이 사라지면 따라잡기도 완전히 숨기며 숨겨진 버튼은 클릭·키보드 선택 대상에서 제외됩니다. 마우스 클릭으로 버튼에 포커스를 남기지 않으며 설정 패널은 정상 불투명도를 유지합니다.

확장을 다시 로드해 기존 탭의 연결이 끊긴 경우, 배속 제어의 주기 통신에서 발생하는 동기 예외도 처리하고 이전 코드의 타이머·키 가로채기·영상 이벤트·프레임 수집을 정리합니다. 새 코드를 사용하려면 등록된 확장을 다시 로드한 뒤 방송 탭도 새로고침하세요.

### 모든 사이트 영상 단축키

- `,`: 0.1배 느리게 / `.`: 0.1배 빠르게 / `/`: **1배속 ↔ 직전 배속** 전환 (0.1~16배 범위, 플레이어 지원 범위 내). 예를 들어 1.7배에서 `/`를 누르면 1배, 다시 누르면 1.7배로 돌아갑니다. 키를 길게 눌러도 `/`는 한 번만 전환합니다. 직전 배속은 탭별 메모리에서 관리합니다.
- 배속 안내는 **브라우저 화면 왼쪽 위 16px**에 24px 글자로 표시합니다. iframe에서 조절해도 상위 화면에 표시하며 플레이어 전체화면과 영상 자체의 전체화면도 지원합니다. 브라우저 밖의 OS 바탕화면에는 표시할 수 없습니다. 안내는 포커스와 클릭을 가로채지 않고 1.6초 후 사라집니다.
- 영상이 없는 페이지에서도 배속을 미리 조절할 수 있고 나중에 생기는 영상에 적용합니다. 배속과 안내를 즉시 반영하며 다른 프레임의 응답을 기다리는 전역 대기열은 사용하지 않습니다. 페이지 자체의 긴 JavaScript 작업으로 브라우저 입력 처리가 멈추는 경우까지 없애지는 못합니다.
- `Shift+,`: 이전 프레임 / `Shift+.`: 다음 프레임. 프레임 이동 시 일시정지합니다.
- 재생 중 관측한 프레임 간격을 이용합니다. 아직 FPS를 읽지 못한 경우에는 30fps로 추정한다고 화면에 표시합니다. 가변 FPS 영상의 정확한 이전 프레임 위치는 브라우저가 제공하지 않으므로 추정 오차가 있을 수 있습니다.
- 일반 HTTP/HTTPS 페이지와 iframe 안의 HTML 영상·오디오를 대상으로 합니다. 브라우저 내부 페이지와 브라우저가 확장을 금지한 페이지에는 적용되지 않습니다.
- 입력창·채팅·편집 영역에서는 키를 가로채지 않습니다. 상위 페이지에서 iframe 영상으로 명령을 전달하고, 새 영상에도 현재 탭에서 지정한 배속을 적용합니다. 탭별 배속은 메모리에서만 관리합니다.
- 수동 배속 중에는 치지직 자동 따라잡기를 멈춰 서로 배속을 덮어쓰지 않습니다.

### 방송 목록 우클릭 미리보기

치지직 전체 방송·홈 목록과 숲 목록에서 방송 **썸네일 위에서만** 우클릭하면 페이지를 이동하지 않고 플레이어 음량 **100%**로 소리와 함께 재생합니다. 제목·스트리머명에서는 원래 우클릭 메뉴를 유지합니다. 다시 썸네일 우클릭, 카드에서 마우스 나감, Esc, 탭 숨김으로 종료합니다. 동시에 한 미리보기만 재생합니다. 썸네일의 원래 우클릭 메뉴는 Shift+우클릭으로 엽니다. 기존 사이트 미리보기를 사용한 경우 종료 시 이전 음소거·음량 상태를 복구합니다.

치지직은 사이트의 `auto-play-info` 응답에 있는 공개 재생 정보를 사용하고 HLS 재생 코드 1.7.3을 포함합니다. 숲은 페이지가 제공하는 공식 PreviewPlayer를 사용하며 `.com`과 이전 `.co.kr` 주소를 지원합니다. 사이트의 로그인·성인·유료·지역·미리보기 시간 제한을 변경하지 않습니다.

### 치지직 검색·광고·화질

- 이모티콘은 기본 선택창으로 넣은 것과 합쳐 한 메시지에 10개까지 입력합니다. 선택한 이모티콘을 교체하는 것은 허용합니다.
- 키를 길게 눌러도 한 번만 삽입합니다. Enter나 일반 편집을 시작하면 이전 단축키의 IME 복원 감시를 종료합니다. 전송 여부를 추측해 입력창을 강제로 지우지 않습니다.
- 검색창에 `rkdwl`을 입력하면 Enter 없이 바로 아래에 **강지** 같은 실제 스트리머가 표시됩니다. 영타 입력은 그대로 유지하며 한글 변환 결과와 원래 영문 결과를 함께 검색해 중복 채널을 합칩니다. 결과를 클릭하거나 위·아래 방향키로 선택한 뒤 Enter로 해당 채널에 이동합니다. 선택하지 않고 검색을 제출하면 한글로 전체 검색합니다. **영문 그대로 검색**으로 원래 영문도 전체 검색할 수 있습니다.
- 먼저 도착한 채널 결과는 다른 응답을 기다리지 않고 표시합니다. 기본 Enter와 검색 버튼도 치지직 자체 검색 핸들러보다 먼저 보정하므로 변환 링크를 추가로 누를 필요가 없습니다.
- 채널의 **보관** 버튼으로 팔로우 없이 저장합니다. 보관 채널·팔로잉 즐겨찾기·정렬 순서는 이 브라우저에만 저장합니다.
- 자동 실시간 따라잡기는 라이브 페이지의 본방 영상에만 적용됩니다. **2초 / 1.5초 / 1초** 중 하나를 고르며 기본은 2초입니다. 자동 보정은 배속만 사용하고 **지금 따라잡기**를 직접 누를 때만 버퍼 안에서 위치를 이동합니다. 표시되는 초는 **최신 버퍼까지의 거리**이며 실제 송출 시각과의 지연 측정값은 아닙니다.
- **지금 따라잡기**로 수동 보정할 수 있습니다. 사용자 지정 배속은 유지하며 재생 위치 변경이나 배속 복귀에 별도 30초 대기를 걸지 않습니다. 자동 따라잡기가 켜져 있으면 되감기 뒤에도 다시 당깁니다. 치즈 플래터의 자동 실시간 따라잡기는 끄고 사용하세요.
- 광고 전용 영상에 음소거와 배속(기본 4배, 1~16배 선택)을 적용하고 종료 시 복구합니다. 본방이 별도로 재생 중이면 광고를 오른쪽 위에 작게 배치합니다. 광고 전 본방 소리가 켜져 있었으면 그 상태를 유지합니다. 사용자가 미리 음소거한 본방을 강제로 켜지 않습니다.
- 광고 배속은 지정값을 상한으로 사용합니다. 버퍼 여유가 적으면 낮추고, `waiting`에서는 즉시 1배속으로 내립니다. 재생 위치가 2초간 멈추거나 버퍼 대기가 1초 이상 이어지면 그 광고는 1배속으로 유지합니다. 다음 광고는 지정값으로 다시 시작합니다. 플레이어가 배속을 반복 복원하면 강제 적용을 중단합니다. 고배속을 거부하면 1배속으로 복구하며, 광고를 강제로 탐색·재시작·재생하지 않습니다. 이 상태는 따라잡기 패널의 재생 상태에 표시합니다. 실제 방송에서 발생한 멈춤의 원인이 버퍼·디코딩·광고 SDK 중 무엇인지는 확인하지 못했습니다.
- 확장이 만든 광고 음소거 이벤트를 광고 SDK의 공통 음소거 처리로 전파하지 않고, 광고 준비 전 본방 음소거 상태를 보존해 종료 시 복원합니다.
- 광고의 **SKIP 버튼이 활성화되면 자동으로 누릅니다**. 실제 광고 전용 영역의 버튼만 대상으로 하며, 숨김·비활성·카운트다운 상태에서는 누르지 않습니다. 건너뛸 수 없는 광고에는 기존 음소거·배속을 적용합니다. 이 설정은 치지직 라이브와 다시보기에 적용됩니다.
- **광고 차단 감지로 인한 360p 제한 보정**은 확인된 치지직 재생정보 터널 응답이 복호화된 직후, 사이트 자체 파서가 읽기 전에 라이브·다시보기 메타데이터의 `dab: true`만 `false`로 보정합니다. 0.5.1~0.5.2의 `JSON.parse` 감시는 이 자체 파서를 거치지 못해 제거했습니다. 응답 인증 표식과 메타데이터 구조가 확인된 경우에만 플래그 토큰을 바꾸고 다른 바이트는 그대로 보존합니다. 영상 주소·트랙·P2P·성인·유료·지역·로그인 정보와 광고 차단 확장 설정은 변경하지 않습니다. 이 기능을 변경하면 탭을 새로고침해야 합니다. AdGuard를 켠 실제 사용자 브라우저에서의 고화질 유지 확인은 별도로 필요합니다.
- 광고 차단 안내는 해당 안내만 숨깁니다. 최고 화질은 플레이어가 제공한 활성 메뉴 항목에서 해상도·FPS가 가장 높은 것을 선택합니다. 고화질용 확장·프로그램 설치나 로그인 조건이 필요한 경우 그 조건을 자동으로 우회하거나 설치하지 않습니다.
- 기능은 팝업의 **검색 · 채널 목록 · 플레이어 설정**에서 개별 설정합니다. 상단 스위치는 Caps Lock 단축키만 제어합니다.
- 팝업 아래에 확장 설치 버전과 현재 페이지 코드 연결 상태를 표시합니다. 소스 버전과 설치 버전이 다르면 확장을 다시 로드하고 탭을 새로고침해야 합니다.
- 치지직에서는 팝업 아래에 **화질 응답 수 / 보정 수 / 실제 디코딩 해상도**도 표시합니다. 메뉴 이름만으로 고화질 복구를 판단하지 않습니다. 이 정보는 현재 페이지 메모리에서만 처리합니다.

광고 유형과 플레이어 구조에 따라 배속이 실제 대기시간을 줄이지 않을 수 있으며, 별도의 본방 영상·오디오가 제공되지 않으면 광고 중 본방 복원은 적용하지 않습니다. 광고 SDK iframe 안의 영상은 지원 대상에서 제외합니다. 실제 광고와 로그인한 채팅에서의 최종 확인은 별도로 필요합니다.

## 설치

1. 이 저장소를 다운로드하거나 복제합니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. 이 저장소 폴더를 선택합니다.
6. 이미 열려 있던 치지직 페이지를 새로고침합니다.

## 사용법

### 일반 이모지 또는 문자열

1. 브라우저 도구 모음에서 확장 프로그램 아이콘을 누릅니다.
2. **+ 키 추가**를 누른 뒤 단축키로 쓸 키 하나를 누릅니다.
3. 해당 키 옆 입력란에 `😂`, `ㅋㅋㅋ` 같은 값을 적습니다.
4. 치지직 라이브 채팅창을 클릭해 커서를 둡니다.
5. Caps Lock을 켜고 해당 키를 누릅니다.

왼쪽 키 버튼을 다시 누르면 언제든 다른 키로 바꿀 수 있습니다. 같은 키를 두 번 등록할 수 없으며 Caps Lock, Enter, Esc, Tab과 보조키는 단축키로 지정할 수 없습니다. 등록 목록이 길어지면 팝업 내부에서 스크롤됩니다.

처음 설치하면 `-`, `=`, `[`, `]`, `;`, `'` 키가 빈 단축키로 준비됩니다. 각 키는 자유롭게 바꾸거나 삭제할 수 있습니다.

### 치지직 전용 이모티콘

1. 치지직에 로그인하고 라이브 채팅을 엽니다.
2. 팝업에서 단축키를 추가하거나 기존 키를 고른 뒤 **치지직 선택**을 누릅니다.
3. 열린 치지직 이모티콘 선택창에서 등록할 이모티콘을 한 번 클릭합니다.
4. 이후 채팅창에 커서를 두고 Caps Lock을 켠 다음 해당 키를 누르면 선택창을 열지 않고 바로 입력됩니다.

등록된 치지직 이모티콘은 팝업에 코드 문자열 대신 실제 아이콘으로 표시됩니다. 0.2.x에서 사용하던 `-`, `=`, `[`, `]`, `;`, `'` 매핑은 처음 팝업을 열 때 새 형식으로 자동 이전됩니다.

단축키는 채팅창에 이모티콘이나 문자열을 입력하기만 하며, 전송하려면 Enter를 직접 눌러야 합니다.

### 입력 진단

한글 키에서 문자가 섞여 나오는 경우 팝업의 **입력 진단**을 펼치고 **이벤트 기록 켜기**를 선택합니다. `치지직 진단 연결됨` 문구를 확인한 뒤 문제를 재현하고, 팝업을 다시 열어 **로그 새로고침**을 누른 다음 로그 칸에서 `Ctrl+A`, `Ctrl+C`로 복사합니다. 연결되지 않으면 치지직 페이지를 새로고침해야 합니다. 로그는 삭제 동작을 제외한 최근 300개 입력 이벤트만 확장 프로그램 로컬 저장소에 보관하며 **로그 지우기**로 삭제할 수 있습니다.

## 안전 범위

- 사이트별 검색·채팅·광고 제어는 치지직에서, 목록 미리보기는 치지직·숲에서만 실행합니다. 영상 속도 단축키는 일반 HTTP/HTTPS 사이트에서 실행합니다.
- 치지직 채팅창에 입력 커서가 있을 때만 단축키가 작동합니다.
- 단축키·기능 설정과 즐겨찾기는 브라우저의 확장 프로그램 로컬 저장소에만 저장됩니다.
- 별도 서버나 계정 정보 수집은 없습니다. 영타 입력 중 검색어를 치지직 공개 검색 API로 전달합니다(쿠키 제외). 우클릭 미리보기는 해당 사이트의 기존 로그인 세션을 사용할 수 있으며, 확장이 로그인 쿠키를 직접 읽거나 저장하지 않습니다. 이모티콘·채널 이미지는 기존 이미지 주소에서 표시합니다.
- 검색창 등 채팅창이 아닌 다른 입력 요소를 편집 중일 때는 단축키를 가로채지 않습니다.

## 알려진 제한

치지직 전용 이모티콘은 등록할 때 코드와 이미지 주소를 저장하고, 사용할 때 치지직의 현재 채팅 편집 모델에 직접 삽입합니다. 치지직이 편집기 또는 이모티콘 코드 형식을 변경하면 기존 매핑을 다시 등록해야 할 수 있습니다.
