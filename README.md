# 치지직 Caps Lock 이모티콘

Caps Lock이 켜진 동안 원하는 키를 치지직 채팅 이모티콘 단축키로 바꾸는 Chrome/Edge 확장 프로그램입니다.

## 0.5.0 편의 도구

### 모든 사이트 영상 단축키

- `,`: 0.1배 느리게 / `.`: 0.1배 빠르게 / `/`: 1배 복귀 (0.1~16배 범위, 플레이어 지원 범위 내).
- `Shift+,`: 이전 프레임 / `Shift+.`: 다음 프레임. 프레임 이동 시 일시정지합니다.
- 재생 중 관측한 프레임 간격을 이용합니다. 아직 FPS를 읽지 못한 경우에는 30fps로 추정한다고 화면에 표시합니다. 가변 FPS 영상의 정확한 이전 프레임 위치는 브라우저가 제공하지 않으므로 추정 오차가 있을 수 있습니다.
- 일반 HTTP/HTTPS 페이지와 iframe 안의 HTML 영상·오디오를 대상으로 합니다. 브라우저 내부 페이지와 브라우저가 확장을 금지한 페이지에는 적용되지 않습니다.
- 입력창·채팅·편집 영역에서는 키를 가로채지 않습니다. 상위 페이지에서 iframe 영상으로 명령을 전달하고, 새 영상에도 현재 탭에서 지정한 배속을 적용합니다. 탭별 배속은 메모리에서만 관리합니다.
- 수동 배속 중에는 치지직 자동 따라잡기를 멈춰 서로 배속을 덮어쓰지 않습니다.

### 방송 목록 우클릭 미리보기

치지직 전체 방송·홈 목록과 숲 목록에서 방송 썸네일에 마우스를 올리고 우클릭하면 페이지를 이동하지 않고 소리와 함께 재생합니다. 다시 우클릭, 마우스 나감, Esc, 탭 숨김으로 종료합니다. 동시에 한 미리보기만 재생합니다. 원래 우클릭 메뉴는 Shift+우클릭으로 엽니다.

치지직은 사이트의 `auto-play-info` 응답에 있는 공개 재생 정보를 사용하고 HLS 재생 코드 1.7.3을 포함합니다. 숲은 페이지가 제공하는 공식 PreviewPlayer를 사용하며 `.com`과 이전 `.co.kr` 주소를 지원합니다. 사이트의 로그인·성인·유료·지역·미리보기 시간 제한을 변경하지 않습니다.

### 치지직 검색·광고·화질

- 이모티콘은 기본 선택창으로 넣은 것과 합쳐 한 메시지에 10개까지 입력합니다. 선택한 이모티콘을 교체하는 것은 허용합니다.
- 키를 길게 눌러도 한 번만 삽입합니다. Enter나 일반 편집을 시작하면 이전 단축키의 IME 복원 감시를 종료합니다. 전송 여부를 추측해 입력창을 강제로 지우지 않습니다.
- 검색창에 `rkdwl`을 입력하면 Enter 없이 바로 아래에 **강지** 같은 실제 스트리머가 표시됩니다. 영타 입력은 그대로 유지하며 한글 변환 결과와 원래 영문 결과를 함께 검색해 중복 채널을 합칩니다. 결과를 클릭하거나 위·아래 방향키로 선택한 뒤 Enter로 해당 채널에 이동합니다. 선택하지 않고 검색을 제출하면 한글로 전체 검색합니다. **영문 그대로 검색**으로 원래 영문도 전체 검색할 수 있습니다.
- 먼저 도착한 채널 결과는 다른 응답을 기다리지 않고 표시합니다. 기본 Enter와 검색 버튼도 치지직 자체 검색 핸들러보다 먼저 보정하므로 변환 링크를 추가로 누를 필요가 없습니다.
- 페이지 왼쪽 아래 **치지직 도구 · 즐겨찾기**에서 현재 채널을 팔로우 없이 저장합니다. 즐겨찾기는 이 브라우저에만 저장되며 네이버 팔로우 상태를 바꾸지 않습니다.
- 자동 실시간 따라잡기는 라이브 페이지의 본방 영상에만 적용됩니다. 재생 가능한 범위와 내려받은 버퍼 안에서 이동하며, 작은 지연은 1.03~1.08배로 보정합니다. 버퍼링 후에는 여유를 늘리고 15초 대기하며 안정 재생 중에는 여유를 조금씩 줄입니다. 표시되는 초는 **최신 버퍼까지의 거리**이며 실제 송출 시각과의 지연 측정값은 아닙니다.
- **지금 따라잡기**로 수동 보정할 수 있습니다. 기존 사용자 배속을 유지하고, 외부 배속 변경이나 왼쪽 방향키로 되감기를 감지하면 자동 보정을 30초 멈춥니다. 치즈 플래터의 자동 실시간 따라잡기는 끄고 사용하세요.
- 광고 전용 영상에 음소거와 배속(기본 4배, 1~16배 선택)을 적용하고 종료 시 복구합니다. 본방이 별도로 재생 중이면 광고를 오른쪽 위에 작게 배치합니다. 광고 전 본방 소리가 켜져 있었으면 그 상태를 유지합니다. 사용자가 미리 음소거한 본방을 강제로 켜지 않습니다.
- 확장이 만든 광고 음소거 이벤트를 광고 SDK의 공통 음소거 처리로 전파하지 않고, 광고 준비 전 본방 음소거 상태를 보존해 종료 시 복원합니다.
- 광고 차단 안내는 해당 안내만 숨기며, 실제 광고 차단 프로그램의 설정이나 서버의 재생 정책을 변경하지 않습니다. 최고 화질은 플레이어가 제공한 활성 메뉴 항목에서 해상도·FPS가 가장 높은 것을 선택합니다. 고화질용 확장·프로그램 설치나 로그인 조건이 필요한 경우 그 조건을 자동으로 우회하거나 설치하지 않습니다.
- 기능은 팝업의 **검색 · 즐겨찾기 · 플레이어 설정**에서 개별 설정합니다. 상단 스위치는 Caps Lock 단축키만 제어합니다.
- 팝업 아래에 확장 설치 버전과 현재 페이지 코드 연결 상태를 표시합니다. 소스 버전과 설치 버전이 다르면 확장을 다시 로드하고 탭을 새로고침해야 합니다.

광고 유형과 플레이어 구조에 따라 배속이 실제 대기시간을 줄이지 않을 수 있으며, 별도의 본방 영상·오디오가 제공되지 않으면 광고 중 본방 복원은 적용하지 않습니다. 광고 SDK iframe 안의 영상은 지원 대상에서 제외합니다. 실제 광고와 로그인한 채팅에서의 최종 확인은 별도로 필요합니다.

### 개발 검증

`node --test tests/core.test.cjs`를 실행합니다. 이 PC에서는 AGENTS.md에 기록한 Node 절대 경로를 사용하세요.

로컬 서버에서 기존 세 harness와 다음 페이지를 확인합니다. 실제 치지직 채팅에는 테스트 문장을 입력하거나 전송하지 않습니다.

- `tests/input-regression-harness.html`: 기본 선택창 이미지·문자 코드 합산 제한, 선택 교체, 중복 요청, 키 반복, Enter 뒤 IME 복원 방지
- `tests/content-limits-harness.html`: 문자 매핑의 코드 개수 제한, 선택 교체, input 이벤트 중복 방지, Caps Lock 꺼짐·일반 입력창 통과
- `tests/search-suggestions-harness.html`: 입력 즉시 실제 채널 표시, 한영 결과 병합·중복 제거, 요청 제한·취소·캐시, 오래된 응답 배제, 실패·설정 꺼짐 처리
- `tests/search-native-harness.html`: 느린 영문 응답과 사이트 자체 Enter·검색 버튼 처리 회귀 검사
- `tests/media-speed-harness.html`: 실제 background worker와 속도·프레임 단축키, 입력창 통과, iframe 명령 전달
- `tests/ad-quality-harness.html`: 광고 준비·SDK 음소거 전파·종료 복원, 최고 화질과 안내 숨김
- `tests/list-preview-harness.html`: 치지직·숲 우클릭 미리보기, 음성·종료·원래 메뉴 보존
- `tests/site-player-harness.html`: 영타 변환·원문 검색 링크, 즐겨찾기, 버퍼 내 따라잡기, 끊김 뒤 대기, 광고 처리 및 종료 후 복구

## 설치

1. 이 저장소를 다운로드하거나 복제합니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. 이 저장소 폴더를 선택합니다.
6. 이미 열려 있던 치지직 페이지를 새로고침합니다.

## 사용법

### 일반 이모지 또는 문자열

1. 브라우저 도구 모음에서 확장 프로그램 아이콘을 누릅니다.
2. **+ 키 추가**를 누른 뒤 단축키로 쓸 키 하나를 누릅니다.
3. 해당 키 옆 입력란에 `😂`, `ㅋㅋㅋ` 같은 값을 적습니다.
4. 치지직 라이브 채팅창을 클릭해 커서를 둡니다.
5. Caps Lock을 켜고 해당 키를 누릅니다.

왼쪽 키 버튼을 다시 누르면 언제든 다른 키로 바꿀 수 있습니다. 같은 키를 두 번 등록할 수 없으며 Caps Lock, Enter, Esc, Tab과 보조키는 단축키로 지정할 수 없습니다. 등록 목록이 길어지면 팝업 내부에서 스크롤됩니다.

처음 설치하면 `-`, `=`, `[`, `]`, `;`, `'` 키가 빈 단축키로 준비됩니다. 각 키는 자유롭게 바꾸거나 삭제할 수 있습니다.

### 치지직 전용 이모티콘

1. 치지직에 로그인하고 라이브 채팅을 엽니다.
2. 팝업에서 단축키를 추가하거나 기존 키를 고른 뒤 **치지직 선택**을 누릅니다.
3. 열린 치지직 이모티콘 선택창에서 등록할 이모티콘을 한 번 클릭합니다.
4. 이후 채팅창에 커서를 두고 Caps Lock을 켠 다음 해당 키를 누르면 선택창을 열지 않고 바로 입력됩니다.

등록된 치지직 이모티콘은 팝업에 코드 문자열 대신 실제 아이콘으로 표시됩니다. 0.2.x에서 사용하던 `-`, `=`, `[`, `]`, `;`, `'` 매핑은 처음 팝업을 열 때 새 형식으로 자동 이전됩니다.

단축키는 채팅창에 이모티콘이나 문자열을 입력하기만 하며, 전송하려면 Enter를 직접 눌러야 합니다.

### 입력 진단

한글 키에서 문자가 섞여 나오는 경우 팝업의 **입력 진단**을 펼치고 **이벤트 기록 켜기**를 선택합니다. `치지직 진단 연결됨` 문구를 확인한 뒤 문제를 재현하고, 팝업을 다시 열어 **로그 새로고침**을 누른 다음 로그 칸에서 `Ctrl+A`, `Ctrl+C`로 복사합니다. 연결되지 않으면 치지직 페이지를 새로고침해야 합니다. 로그는 삭제 동작을 제외한 최근 300개 입력 이벤트만 확장 프로그램 로컬 저장소에 보관하며 **로그 지우기**로 삭제할 수 있습니다.

## 안전 범위

- 사이트별 검색·채팅·광고 제어는 치지직에서, 목록 미리보기는 치지직·숲에서만 실행합니다. 영상 속도 단축키는 일반 HTTP/HTTPS 사이트에서 실행합니다.
- 치지직 채팅창에 입력 커서가 있을 때만 단축키가 작동합니다.
- 단축키·기능 설정과 즐겨찾기는 브라우저의 확장 프로그램 로컬 저장소에만 저장됩니다.
- 별도 서버나 계정 정보 수집은 없습니다. 영타 입력 중 검색어를 치지직 공개 검색 API로 전달합니다(쿠키 제외). 우클릭 미리보기는 해당 사이트의 기존 로그인 세션을 사용할 수 있으며, 확장이 로그인 쿠키를 직접 읽거나 저장하지 않습니다. 이모티콘·채널 이미지는 기존 이미지 주소에서 표시합니다.
- 검색창 등 채팅창이 아닌 다른 입력 요소를 편집 중일 때는 단축키를 가로채지 않습니다.

## 알려진 제한

치지직 전용 이모티콘은 등록할 때 코드와 이미지 주소를 저장하고, 사용할 때 치지직의 현재 채팅 편집 모델에 직접 삽입합니다. 치지직이 편집기 또는 이모티콘 코드 형식을 변경하면 기존 매핑을 다시 등록해야 할 수 있습니다.
