# 0.10.32 검증 기록 — 2026-11-19

## 원인과 변경

겹치기 여부가 플랫폼 공통 `chzzkFreeChatLayout`/`soopFreeChatLayout`의 `enabled`에 저장되고, 다른 탭의 저장소 변경 수신 시 컨트롤러를 다시 만들면서 그대로 적용됐다. 수정 전 실제 Edge의 두 테스트 페이지에서 첫 탭의 겹치기를 끄자 두 번째 탭도 꺼지는 것을 재현했다. `tests/free-chat-tabs.browser.cjs`는 `chzzk: toggling the first tab changed the second tab`으로 실패했다.

겹치기 켬·끔을 탭별 sessionStorage에 분리했다. 새 탭 세션은 꺼짐이며 새로고침에서는 해당 탭의 선택을 복원한다. 기존 공통 enabled 값은 읽지 않고 새 배치 저장에서도 제외한다. 위치·크기·모니터별 배치·투명도·오른쪽 폭은 기존 플랫폼 공통 설정을 유지한다. 공통 배치가 갱신되거나 팝업 기능 설정·기존 스크립트 감지 때문에 컨트롤러가 재시작돼도 탭의 선택을 유지한다. sessionStorage 사용이 거절되면 현재 페이지 메모리로 계속 동작한다.

하단 겹치기 버튼, 원래 배치 버튼, Alt+Shift+C 모두 같은 경로를 사용한다. 팝업의 자유 배치 채팅 설정은 모든 탭의 기능 전체를 켜고 끄는 설정으로 유지하고 설명을 보완했다. 추가 권한은 없다.

## 검증

- 루트 JavaScript 전체 문법 검사, 변경한 브라우저 검사기 문법 검사, manifest 0.10.32 파싱과 git diff --check 통과.
- 번들 Node `--test tests/*.test.cjs`: 50개 통과, 실패·건너뜀 없음.
- `tests/free-chat-tabs.browser.cjs`: 실제 Edge의 복수 페이지와 공유 확장 저장소 모형으로 치지직·숲 각각 탭별 켬·끔, 새 탭 기본값, 켬·끔 양쪽 새로고침 복원, 단축키, 원래 배치 버튼, 공통 배치 갱신, 전체 기능 껐다 켜기, 채팅 DOM 교체, 기존 작성 문장 보존 통과. 수정 전 실패한 동일 회귀 검사 통과.
- `tests/media-zoom.browser.cjs --whale`: 격리 웨일에서 브라우저 모형 검사 225개 통과(확대 33개, 하단 메뉴·채팅 192개). 실제 unpacked 0.10.32 서비스 워커 로드, 재생 유지, 전체화면 입력과 iframe·팝업 IPC 검사 통과. 페이지 실행 예외 없음. 임시 프로필은 종료 시 자동 정리했다.

다중 탭 겹치기 검사는 실제 브라우저에서 확장 저장소 전파를 모사한 테스트이며, 사용자 로그인 방송에서 확인한 결과는 아니다. 실제 채팅 메시지를 입력하거나 전송하지 않았다. 적용에는 확장 재로드와 방송 탭 새로고침이 필요하다.

## 배포본과 저장 공간

`tools/package-release.py --clean`으로 런타임 37개 파일의 모든 바이트 및 manifest 참조를 검증했다. 현재 0.10.32와 Git 원본이 일치하는 복구용 0.10.31을 보존했다. ZIP SHA-256: `28e9150f06dd54b41f4b132dd76a9e3cc430879a7e4ba2c4dcfdf2edef3ea8ee`.

검증된 구버전 0.10.30 ZIP을 자동 정리해 ZIP 총합 13,135,300 → 12,806,458바이트, 328,842바이트를 확보했다. 새 ZIP 생성 전 총합은 12,804,690바이트로 이번 배포 후 순증은 1,768바이트다. 동일 버전 Git 원본 전체와 일치하지 않는 기존 ZIP 33개 및 이전 진단 자료는 보존했다. 자동 정리는 기존 패키징 완료 경로에 연결돼 있으며, 이번 검사에서도 현재·직전 복구용 보존과 불확실한 자료 보존을 확인했다. unpacked 설치는 프로젝트 루트를 사용하므로 별도 앱 설치본을 만들지 않았다.
