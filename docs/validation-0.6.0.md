# 0.6.0 검증 기록 — 2026-10-29

## 변경

- 왼쪽 아래 고정 패널 제거. 라이브 따라잡기 설정은 가위 왼쪽, 팔로우 없이 저장하는 보관 버튼은 팔로우/팔로잉 왼쪽으로 이동했다.
- 팔로잉 목록의 빈 별표로 즐겨찾기를 지정하며, 상단 그룹과 가로 구분선을 표시한다. 순서 편집은 드래그 손잡이와 위·아래 버튼을 제공한다. 즐겨찾기와 일반 그룹 내부의 순서를 각각 저장한다.
- 기존 `favorites` 저장 데이터는 보관 채널로 계속 읽는다. `followingFavorites`와 `channelOrder`는 별도 키다. 저장 직전 최신 값을 읽고 같은 페이지의 변경을 직렬 처리한다.
- 보관 채널을 사이드바 목록에 합치며 기존 팔로잉 행과 중복하지 않는다. 보관 표시와 공개 방송 상태를 표시한다. 기본 팔로잉 영역이 없으면 실제 `#sidebar` 안에 보관 영역을 추가한다.
- 상시 펼치기는 기본 켜짐이며 팝업에서 변경한다. 팔로우 계정 상태를 바꾸는 버튼이나 API는 사용하지 않는다.

## 근거와 실제 페이지 확인

사용자가 첨부한 두 이미지의 가위와 팔로잉 버튼을 기준으로 위치를 정했다. 현재 치지직의 공개 코드에서 팔로잉 `nav[aria-label]`와 기본 행·더보기 구조, `.custom__clip-button`을 확인했다. 실제 로그아웃 치지직 페이지의 DOM을 읽어 사이드바가 `#sidebar`이고 검색 헤더 `#header`와 별개임을 확인했다. 팔로우 버튼의 너비 89px 툴팁 부모 바깥에 보관 버튼을 넣도록 조정했다. 이 페이지는 플레이어가 표시되지 않아 실제 재생 중 가위 옆 배치는 로컬 fixture로 검증했다.

기본 행은 복제하거나 옮기지 않는다. CSS 표시 순서만 바꾸며 기본 링크·hover 이벤트를 유지한다. 새 채팅 메시지마다 목록 전체를 다시 처리하지 않도록 DOM 관찰 범위를 거른다.

## 통과한 검사

- 루트 JavaScript 문법 검사, manifest JSON 파싱, `git diff --check`.
- Node 9개 테스트: 기존 코어·화질 응답 검사 및 채널 정렬 그룹/순서/원본 보존 검사.
- 로컬 브라우저 전체 회귀 검사: 15개 묶음, 100개 항목. 새 채널 UI 24개와 기존 검색·이모티콘·광고·속도·미리보기·팝업 검사를 포함한다.
- 새 UI 검사는 별표·구분선·저장·드래그·이동 버튼·보관 중복 제거·표시·빠른 변경·네이티브 이벤트 유지·설정 해제·전체 목록 제거/복구·헤더 오삽입 방지를 확인한다.
- 공개 채널 API의 ID·이름·이미지·openLive 필드 존재를 실제 응답에서 확인했다. 브라우저 fixture의 채널 응답·로그인 목록·플레이어 상태는 모사했다.
- 실제 채팅에 입력하거나 전송하지 않았다. 실제 팔로우/팔로우 해제도 실행하지 않았다.

## 적용과 한계

등록된 개발 확장의 프로젝트 폴더에 반영했다. 도구에서 확장 관리 화면에 접근할 수 없어 사용자의 확장을 직접 다시 로드하지 못했다. 확장 다시 로드 후 치지직 탭 새로고침이 필요하다. 로그인한 사용자 팔로잉 목록과 실제 재생 중 플레이어에서의 최종 확인은 별도다. 미리보기 이미지는 실제 방송 화면이 아닌 로컬 fixture임을 표시한다.

화질 보정은 0.5.3에서 사용자가 업데이트 후 1080p 복구를 보고한 상태를 유지한다.
