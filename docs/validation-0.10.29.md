# 0.10.29 검증 기록 — 2026-11-17

방송 영상 자체의 확대와 확대 후 위치 이동을 추가했다. 기존 저장소에는 영상 확대 기능이 없었으며 브라우저 확대는 영상 전용 조작이 아니었다. `media-zoom.js`가 영상에만 배율·이동·클리핑을 적용하고 채팅·기본 플레이어 UI 크기는 유지한다. 지원 배율은 100~500%다.

영상 오른쪽 위 조절판과 확장 팝업에 배율·방향·초기화 버튼을 제공한다. Alt+휠은 포인터 위치를 중심으로 확대하고 Alt+드래그는 영상을 잡아 옮긴다. Alt+=/−, Alt+방향키, Alt+0, Alt+Z도 지원한다. 조절판의 `화면 끌어서 이동`을 켜면 수정키 없이 터치·마우스로 옮긴다. 이동 범위를 영상 가장자리로 제한하며 가운데/100% 초기화를 구분한다. 입력창·IME·다른 조합키는 제외한다.

프레임별 영상 크기를 보고해 팝업과 상위 페이지의 명령을 가장 큰 영상 iframe에 전달한다. 확장 팝업 URL만 다른 탭을 지정할 수 있고 콘텐츠 스크립트는 자신의 탭만 제어한다. 광고·확장 소리 미리보기는 제외하고 전역 배속 설정과 독립 동작한다. 배율·위치는 영상별 페이지 메모리에서만 유지한다. 기능 해제·영상 교체·확장 무효화에서 원래 인라인 스타일과 우선순위를 복원한다. 확장 권한은 추가하지 않았다.

- 격리 Edge에서 실제 trusted pointer로 플레이어 전체화면(DIV)과 영상 단독 전체화면(VIDEO)을 검사했다. 1280px 화면의 영상 요소 폭이 200%에서 2560px이 되었고 조절판의 방향 버튼으로 이동했다. 영상 단독 전체화면에서는 이동 버튼, 수정키 없는 드래그, 슬라이더를 실제 마우스로 검사했다.
- 전체화면 바깥 popover가 그려져도 클릭은 영상에 전달되는 경로를 재현했다. 플레이어 전체화면에서는 조절판을 해당 요소 안에 둔다. 영상 단독 전체화면은 자식 조절판이 렌더링되지 않아 바깥 popover를 유지하고 그 위치로 전달된 영상 포인터를 표시된 확장 컨트롤에만 연결한다. 단순 popover 재개방과 크기 보정만으로는 해결되지 않아 그 가설은 제거했다. 최종 코드의 `fullscreenchange` 재개방은 바깥 popover를 새 전체화면 위에 표시하기 위한 처리다.
- 실제 unpacked 확장의 manifest 로드를 확인했다. canvas 영상 스트림을 재생하며 키·마우스 이동 뒤에도 재생 상태와 시간 진행이 유지되고 원래 UI 폭이 변하지 않았다. 새 브라우저 프로필은 종료 후 자동 정리했다.
- 실제 확장 팝업 페이지에서 cross-origin iframe 영상을 확대·이동·100% 복구했다. 팝업을 별도 탭으로 열었으므로 action 팝업의 소유 탭 조회 결과 하나만 검사 페이지 ID로 모사했다. 나머지 콘텐츠 스크립트·서비스 워커 IPC와 iframe은 실제 동작이다. 실제 브라우저 action 팝업 창을 열었다고 집계하지 않는다.
- 로그아웃한 치지직 공개 다시보기 `https://chzzk.naver.com/video/15964028`에서 실제 unpacked 확장의 Alt+= 입력 후 영상 폭 687px → 858.75px(125%), Alt+오른쪽 후 `translate: -8.5875px`, Alt+0 후 원래 폭 복구를 확인했다. 페이지 실행 예외는 0건이었다.
