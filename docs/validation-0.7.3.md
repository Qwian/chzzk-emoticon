# 0.7.3 검증 기록 — 2026-10-29

## 변경

- 키보드 중심 아이콘을 민트색 재생·편의 도구 마크로 교체했다. SVG 원본과 PNG 생성 스크립트, 16·32·48·128px 및 512px 마스터를 포함한다.
- 브라우저 툴바 아이콘에 현재 탭의 실제 영상·오디오 배속을 숫자로 표시한다. 보통 재생은 `1`, 자동 따라잡기는 `1.03`·`1.08`, 수동 배속은 `1.5`·`2` 등으로 표시한다. 툴팁에도 현재 배속을 설명한다.
- 명령의 목표 배속 대신 미디어 요소가 보고한 실제 배속을 사용한다. 탭과 iframe별 상태를 구분하고 큰 본방 영상을 우선하며 기존 치지직 광고 전용 영역은 제외한다.
- 미디어 및 마지막 iframe 제거, 페이지 로딩에서 이전 배속 표시를 정리한다. 미디어 이벤트는 50ms로 합치고 기존 4초 상태 보고를 유지한다. 같은 숫자에는 action API 쓰기를 반복하지 않는다.
- 설정 팝업의 영문 표제와 툴팁을 편의 도구에 맞게 갱신했다. 추가 권한이나 외부 요청은 없다. 실제 배속의 브라우저 내부 처리를 개인정보 문서에 명시했다.

## 검증

- 루트 JavaScript 전체, worker와 아이콘 생성기 문법 검사 통과. manifest JSON 파싱, 참조 파일 존재, PNG 크기·형식, git diff --check 통과.
- Node 25개 검사 통과: 기존 core·quality·channel-data 16개 및 background 배속 표시 9개. 탭별 구분, iframe 우선순위·제거·만료, 정상·수동·자동 배속, 오디오, 잘못된 값, 외부 발신자, 중복 쓰기 억제, 닫힌 탭 오류 복구를 확인했다.
- 로컬 media-speed 브라우저 검사 20개 통과: 실제 content script와 background worker를 사용해 배속 숫자, 단축키, 60fps 프레임 이동, 입력창 제외, iframe 전달, 광고 제외, 오디오, 미디어·iframe 제거를 확인했다. chrome.action API 호출은 모사했다.
- 연결 해제 5개 시나리오 31개 검사 통과. 동기 예외·비동기 거부·확장 ID 소실·키 입력 경로·일시 통신 실패를 확인했다. 전역 오류와 미처리 Promise 거부는 없었다.
- 새 128px 아이콘을 시각 확인했고 로컬 popup harness가 0.7.3 스크립트로 열리는 것을 확인했다.

## 적용 제한

등록된 웨일 창은 도구가 창 소유자를 확인하는 단계에서 오류가 발생했다. 현재 창 목록을 다시 조회한 뒤 한 번 재시도했지만 같은 오류가 반복되어 설치본을 다시 로드하지 못했다. 확장 관리에서 기존 확장을 다시 로드한 뒤 사용 중인 방송·영상 탭을 새로고침해야 한다. 실제 확장 로드 및 툴바 표시·실제 방송 재생 검증은 완료했다고 주장하지 않는다. 실제 치지직 채팅 입력·전송은 수행하지 않았다.
