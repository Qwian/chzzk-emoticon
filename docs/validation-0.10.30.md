# 0.10.30 검증 기록 — 2026-11-17

## 변경

- 영상 확대와 채팅 겹치기를 네이티브 플레이어 하단의 따라잡기 앞에 같은 그룹으로 배치했다. `player-view-controls.js`를 두 기능이 함께 사용하며 치지직·숲·유튜브의 기존 컨트롤 행을 찾는다. 채팅 겹치기는 기존과 같이 넓은 화면/스크린모드에서 제공한다.
- 우상단 확대 버튼과 별도로 고정되어 있던 채팅 겹치기 버튼을 제거했다. 기본 컨트롤이 사라지면 두 버튼과 열린 확대 조절판도 숨긴다. 조절판은 하단 버튼 위로 열고, 드래그 영역에서 하단 컨트롤을 제외한다. 컨트롤 DOM 교체 후 중복 없이 재배치한다. 네이티브 메뉴가 없는 일반 영상의 임시 버튼도 하단으로 옮겼다.
- 공개 치지직 본편에서 조절판 위로 마우스를 움직일 때 네이티브 컨트롤과 조절판이 숨는 문제를 재현했다. 조절판 DOM도 플레이어 안에 두어 포인터 움직임이 기본 플레이어에 전달되도록 수정했다. 전체화면의 top-layer 및 영상 단독 전체화면 처리는 유지한다.
- Alt+휠의 포인터 위치 제한을 해제하고 `deltaY`와 `deltaX`를 모두 지원한다. 영상 위에서는 포인터 기준, 밖에서는 현재 위치를 유지하며 조절한다. iframe 명령에도 0.1배 단위를 전달한다. 입력창과 Ctrl/Meta 조합 제외, 일반 휠과 Alt+드래그는 유지한다.
- 수정 전 실제 브라우저 입력에서 세로 휠은 110%로 확대했으나 이어진 가로 휠은 여전히 110%였다. 기존 코드가 가로 축과 영상 밖 포인터를 무시하는 것은 확인했지만 사용자 웨일에서 세로 휠까지 작동하지 않았던 정확한 입력 상태는 확인하지 못했다. 이를 사용자 환경의 단일 확정 원인으로 주장하지 않는다.
- 팝업 조회/조절판 열기 시 프레임 크기를 다시 수집한다. 새 iframe이 로드된 직후 작은 상위 영상이 먼저 보고돼 잘못 선택되던 간헐적 검사 실패를 보완했다.
