# 0.10.7 검증 기록 — 2026-11-01

## 오류 재현과 범위

사용자가 보고한 오류는 `ad-skip.js`의 `ChzzkAdDom is not defined`이다. 0.10.6은 광고 추적을 별도 `document_start` 항목에서 초기화하지만, `document_idle` 스킵 타이머에서는 초기화 여부를 확인하지 않고 참조했다. 플레이어 도구도 시작 순간의 객체를 상수에 보관하므로 나중에 객체가 생겨도 회복하지 못했다.

로컬 검사에서 추적 객체를 나중에 로드해 기존 코드의 동일한 ReferenceError를 재현했다. 플레이어의 직접 따라잡기 요청에서도 undefined의 wrappers 참조 오류가 발생했고, 객체 초기화 후에도 광고 음소거가 복구되지 않았다. 사용자 탭에서 최초 초기화가 빠진 정확한 계기까지 확인한 것은 아니다.

## 수정

- 제거되는 광고를 관찰하는 `document_start` 초기화를 유지한다. 같은 `ad-dom.js`를 idle 소비자 앞에서도 실행해 초기화를 보장한다. 기존 객체가 있으면 즉시 반환하므로 추적 상태와 관찰자를 중복 생성하지 않는다.
- 스킵과 플레이어 tick에서 `globalThis.ChzzkAdDom`을 매번 읽는다. 아직 없으면 처리를 대기하고, 준비된 뒤 자동 복구한다.
- 새 초기화 회귀 검사와 적용 안내를 추가했다. 저장 데이터와 권한은 변경하지 않았다.

## 검증

- 초기화 회귀 8개 통과. 기존 0.10.6은 이 중 4개 실패하며 보고된 ReferenceError를 포함한 pageerror가 발생한다. 수정본은 pageerror 없음.
- 기존 제거 광고 12개, 광고 배치 8개, 스킵 13개, 음소거/화질 6개, 소리 복원 7개, 배속 19개, 사이트/플레이어 11개 통과. 초기화 검사 포함 총 84개이며 모두 로컬 모형 검사다.
- 임시 Edge 프로필에서 실제 unpacked 확장 0.10.7 로드 성공. 정상 manifest에서 시작·idle 단계가 같은 객체를 유지하며 모형 광고 스킵·음소거 성공. 별도 임시 복사본에서 시작 단계의 ad-dom만 생략해도 idle 단계 초기화와 스킵·음소거가 성공했다. 두 조건 모두 확장 실행 세계의 예외 없음.
- 루트 JavaScript 전체 문법 검사, manifest 파싱·참조 스크립트 존재 확인, Node 검사 29개, `git diff --check` 통과.
- 사용자 웨일의 실제 방송·광고 재발 여부와 로그인 채팅 입력·전송은 검증하지 않았다. 실제 채팅을 조작하지 않았다.

적용하려면 확장을 다시 로드한 뒤 기존 치지직 탭도 새로고침해야 한다.
