# 0.9.3 검증 기록 — 2026-10-29

따라잡기 팝업에 바깥 클릭 닫기 처리를 추가했다. window의 click 캡처 단계에서 Shadow DOM을 포함한 composedPath를 확인한다. 따라잡기 버튼과 팝업 내부의 클릭은 유지하고 바깥 클릭에서는 details만 닫는다. 클릭의 기본 동작·전파·포커스는 막지 않는다.

- 기존 로컬 채널 도구 화면에서 실제 브라우저 클릭으로 열기→내부 체크박스 조작 후 열린 상태 유지→바깥 제목 클릭 후 닫힘을 확인했다.
- 따라잡기 버튼을 다시 눌러 닫기와 Space 키로 열기도 확인했다. 해당 검사 탭 warning/error 로그 없음.
- 기존 채널 도구 브라우저 검사 34개 및 필수 core Node 검사 6개 통과. 루트 JavaScript 전체 문법 검사, manifest JSON 파싱과 git diff --check 통과.
- 실제 방송·채팅에서 입력하거나 메시지를 전송하지 않았다. 설치된 확장의 직접 재로딩 검증은 하지 않았으며 확장 다시 로드와 치지직 탭 새로고침이 필요하다.
