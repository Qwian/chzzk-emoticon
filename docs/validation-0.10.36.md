# 0.10.36 검증 기록 — 2026-11-22

## 동작

사용자가 별도로 요청한 **방송 입장 후 채팅창을 열지 않아도 대화 보관**을 구현했다. 입장 전 기록 조회와 구분하며, 0.10.33의 철회 사유를 변경하지 않는다.

MAIN-world `soop-chat-history.js`는 원래 닫힌 채팅을 건너뛰는 일반 메시지·OGQ·시스템 메시지 처리에서 동기 포맷팅 동안만 열린 상태를 제공한다. 원래 필터를 거친 표시 대기열을 최근 300개로 제한하고, 기본 타이머는 계속 닫힌 상태로 인식한다. 원래 openChat이 실행되면 SOOP이 대기열을 표시한다. 닫기 직전 표시 대기 중인 메시지도 유지한다. 입력창·초점·채팅 DOM을 바꾸거나 메시지를 전송하지 않는다.

`soop-chat-history-settings.js`가 독립된 `features.soopChatHistory`를 연결한다. 기본 켜짐이며, 자유 배치·겹치기 기능을 꺼도 유지된다. 팝업에 별도 켬·끔을 제공한다. 늦은 기본 컨트롤러 초기화와 교체 시 연결하고, 기능을 끄면 원래 메서드를 복원한다. 기본 채팅 지우기·방송 변경의 초기화는 유지한다. 대화는 페이지 메모리에만 남고 확장 저장소에는 설정만 저장한다.

## 검증 결과

- 루트 JavaScript 문법 검사, manifest 파싱, git diff --check 통과.
- 번들 Node로 테스트 57개 실행·통과, 실패·건너뜀 없음. 처음부터 닫힌 패널, 보관 상한, 원래 필터·초기화, 오류 후 열린 상태 복원, 컨트롤러 교체, 설정 비활성화, 늦게 완료된 설정 읽기와 변경 이벤트 순서 포함.
- `tests/soop-chat-history.browser.cjs`: 격리 Whale에서 실제 unpacked 0.10.36과 MAIN/isolated 주입, 처음부터 닫힌 모형의 메시지·OGQ 보관과 재열기, 1,000개 입력 중 최근 300개 유지, 원래 초안·필터·초기화, 실제 팝업에서 끄기·다시 켜기, 자유 배치 비활성화 상태와 독립 동작, 컨트롤러 교체 통과. 확장 페이지 오류 없음.
- `tests/soop-chat-history.browser.cjs --public`: 공개 생방송 `khm11903`에서 프로필의 기본 채팅을 처음부터 닫고 입장했다. 채팅을 한 번도 열지 않은 상태에서 실제 수신 9개가 쌓였고, 첫 열기 때 9개 모두 기본 채팅 DOM에 표시됐다. 같은 방송에서 기능을 끄고 닫으면 대기열은 0개였다. 자유 배치 기능은 전체 과정에서 꺼진 상태였다. 확장 출처의 페이지 실행 오류 없음. 실제 채팅 입력·전송 없음. 결과: `artifacts/soop-history-live-0.10.36.json`.
- 첫 공개 진단 대상은 이미 종료된 홍보 링크여서 수신을 확인할 수 없었다. 현재 인기 방송 링크를 선택해 위 검증을 완료했으며 실패 기록을 성공 근거로 사용하지 않았다.
- `tests/free-chat-tabs.browser.cjs`: 치지직·SOOP의 탭별 겹치기, 새 탭·새로고침, 단축키, 배치 공유, 기능 재시작·DOM 교체 통과.
- 모든 테스트용 Whale 프로필은 종료 후 자동 정리했다. 사용 중인 Whale 프로필은 computer-use가 현재 창을 바인딩하지 못하는 오류로 확장 재로드를 수행하지 못했다. 실제 사용자 프로필에는 확장 다시 로드와 숲 탭 새로고침이 필요하다.
