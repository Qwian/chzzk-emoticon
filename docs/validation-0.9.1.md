# 0.9.1 검증 기록 — 2026-10-29

## 수정

- 유튜브 큰 극장 모드에서 바깥 영역만 늘리고 내부 플레이어·영상의 픽셀 크기는 보정하지 않던 경로를 수정했다. `#player-container`부터 `#movie_player`, `.html5-video-container`, `video.html5-main-video`까지 영역 크기를 따르도록 하고 영상은 contain으로 비율을 유지한다. CSS는 큰 극장 모드에만 적용하고 기능 해제 시 기본 스타일로 돌아간다.
- 플레이어 영역을 ResizeObserver로 감시해 크기가 바뀌면 기본 플레이어에도 resize를 알린다. 이 알림으로 드래그 중인 채팅 폭이 이전 저장값으로 되돌아가지 않게 구분하며 해제 시 감시·예약 작업을 정리한다.
- 배속 안내는 최대 36px에서 24px로, 상자 padding은 12×22px에서 8×14px로 줄였다. 왼쪽 위의 동일 가로·세로 여백, 작은 영상 경계 보정과 전체화면 popover는 유지한다.

## 근거와 검증

- 실제 공개 YouTube NASA 영상 페이지의 극장 모드 DOM을 조회했다. `#player-full-bleed-container > #player-container > ytd-player > #container > #movie_player > .html5-video-container > video` 구조와, 높이 0인 미디어 래퍼·영상에 직접 쓰인 width/height/left/top 픽셀 값을 확인했다.
- 그 구조와 고정 픽셀 값을 사용하는 새 검사 페이지에서 기존 코드의 내부 영상 크기·위치 검사 5개가 실패했다. 수정 후 채팅 없는 극장 모드, 옆 채팅, 채팅 폭 변경, 기본 resize 통지, 늦은 픽셀 값 변경, 드래그 중 폭 유지, 영상 비율, iframe 유지, 기능 해제 복원 9개가 통과했다.
- 기본 1280×720 검사 창에서 채팅을 96px로 줄였을 때 영상과 영역이 모두 x=0, y=0, width=1176, height=720으로 일치했다. 브라우저 viewport 변경 요청은 실제 크기에 반영되지 않아 다른 해상도를 검사했다고 집계하지 않았다.
- 기존 유튜브 배치 검사 25개 및 기존 사용자 스크립트 선행 검사 26개 통과. F/T, 전체화면 클릭, 접힌 채팅, 설정 해제·재개와 SPA 교체를 포함한다.
- 배속 브라우저 검사 26개 통과. 640×360 영상의 안내 글자 24px, 상자 높이 50px 미만, 같은 왼쪽·위 여백과 기존 단축키 동작을 확인했다.
- Node 28개, 루트 JavaScript 전체 문법 검사, manifest JSON 및 content script 참조 파일 존재 확인, git diff --check 통과.
- 크기 검사 탭의 도구 콘솔에는 MutationObserver 대상 관련 오류 1건이 있었으나, 확장 JavaScript를 모두 뺀 동일 DOM 대조 페이지에서도 같은 오류가 발생했다. 검사 페이지에서 수집한 확장 실행 오류는 없었다. 이를 확장의 새 오류나 모든 콘솔 오류가 해결됐다는 근거로 집계하지 않았다.

위 자동 검사 합계는 114개다. 실제 YouTube DOM 조회와 로컬에서 변경 코드를 실행한 결과를 구분한다. 사용자의 브라우저에 설치된 확장을 직접 다시 로드하거나 그 환경의 실제 재생으로 확인한 결과는 아니다. 확장 다시 로드 후 유튜브 탭도 새로고침해야 한다.
