# 0.9.0 검증 기록 — 2026-10-29

## 변경

- 사용자가 제공한 YT Fake Fullscreen 4.0을 확장에 통합했다. F는 화면 높이를 채우는 극장 모드, T는 실제 전체화면이며 마우스 전체화면 버튼은 극장 모드를 전환한다. T가 발생시킨 클릭을 다시 극장 모드로 가로채던 원본의 경로를 분리했다. 상단바 잠깐 표시와 페이지 이동을 지원한다.
- 펼친 유튜브 기본 라이브 채팅을 영상 오른쪽에 표시하며 경계로 폭을 조절·저장한다. 원래 iframe·문서를 이동하거나 재생성하지 않는다. 접힌 채팅을 강제로 열지 않는다.
- 사용자가 첨부한 넥슨 라이브 배치 스크립트 1.0.0을 통합했다. 기존 AspectRatio/SideContent와 공개 다시보기에서 확인한 Content_inner/portal ReplayChatPanel 구조를 처리한다. Alt+Shift+M으로 전환하고 F로 영상과 채팅을 함께 전체화면에 표시한다. 새 확장 설정이 없을 때만 사이트의 기존 nlf.enabled/nlf.width를 읽고 원래 값을 변경하지 않는다.
- 두 사이트 모두 고정 240px 최소 폭 없이 1px부터 현재 뷰포트 안에서 조절한다. 드래그·방향키·Home·두 번 클릭을 지원하며 원래 사용자 스크립트의 스타일 표식이 있으면 중복 적용을 멈춘다. 팝업에서 별도로 끌 수 있다.
- 치지직 생방송 광고 종료 시 한 번만 음소거를 복원하던 경로를 보완했다. 종료 후 5초 동안 지연된 음소거·음량 0 변경과 본방 요소 재연결을 처리한다. 종료된 광고 영상의 래퍼가 남아 있어도 광고 준비 상태로 오인하지 않는다. 원래 음소거와 페이지 음량 컨트롤·M 키로 나타낸 사용자 의도를 유지하며 채널 이동·기능 해제 시 복원을 중단한다. 본방 volumechange는 차단하지 않는다.

## 검증

- 루트 JavaScript 전체 문법 검사, manifest JSON 파싱·content script 참조 파일 존재, git diff --check 통과.
- Node 28개 통과: core, quality bridge, channel data, media background.
- 배치 브라우저 검사 97개 통과: 유튜브 25, 유튜브 기존 스크립트 선행 26, 넥슨 기존 구조 15, 새 구조 15, 기존 스크립트 선행 16. 폭 96px 저장·복원, 기존 채팅 문서·작성 내용 보존, F/T 및 전체화면 클릭 구분, 입력창 제외, 반복 키, 상단바 유지·숨김, 접힌 채팅, 기능 해제·재개, SPA 교체·이동과 중복 스크립트 대기를 확인했다.
- 광고 소리 전용 검사 7개 통과: 지연된 음소거·음량 0, 시간창 종료, 종료 영상의 잔류 래퍼, 기존 음소거, 본방 요소 교체, 종료 순간 본방이 없다가 재연결, 채널 이동.
- 기존 브라우저 검사 35개 통과: site-player 10, ad-quality 6, ad-speed 19. site-player의 다음 광고 전 수동 음소거 모사는 앞 광고의 복원 시간창이 끝난 뒤 수행하도록 시간을 맞췄다.
- 위 자동 검사 합계 167개 통과. 새 배치·소리 검사 페이지의 warning/error 로그 없음.
- 소리 검사 페이지에서 실제 마우스 클릭으로 광고 시작→종료→늦은 SDK 음소거를 실행하면 muted=false, volume=0.4로 복원됐고, 이어 페이지 음소거 버튼을 직접 누르면 같은 시간창에서도 muted=true, volume=0.4를 유지했다.
- 팝업에 유튜브·넥슨 기능 설정이 기본 켜짐으로 표시되는 것을 확인했다.

미디어 상태·전체화면·확장 저장 API는 로컬 검사에서 모사했다. 공개 YouTube 영상 페이지와 넥슨 다시보기의 현재 DOM 구조는 조회했지만, 해당 실제 사이트에서 변경 코드를 설치·실행한 검증은 하지 않았다. 실제 CHZZK 생방송 광고에서 사용자 증상의 원인을 확정하거나 재발이 없음을 확인한 결과가 아니다. 실제 채팅에 입력하거나 메시지를 보내지 않았다.

설치된 확장을 다시 로드하고 대상 탭을 새로고침해야 새 코드가 적용된다. 대체할 YT Fake Fullscreen·넥슨 라이브 배치 사용자 스크립트는 꺼야 한다. 확장이 템퍼몽키 설정을 변경하지 않는다.
