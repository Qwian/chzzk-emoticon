# 0.9.5 검증 기록 — 2026-10-30

## 원인과 변경

공개 치지직 채널 메인에서 실제 DOM을 읽어 `main`이 없고 콘텐츠가 `div#layout-body` 아래에 있음을 확인했다. 채널 이름은 `h2._name_*`, 프로필 사진은 현재 채널의 라이브 링크 안에 있고, 팔로우 버튼은 `div._follow_*`에 들어 있었다. 기존 코드는 `main button`만 검색해 메인에 보관 버튼을 붙이지 못했다.

채널 정보와 팔로우 버튼 검색에 `#layout-body`를 지원하고, 메인 프로필 이름과 현재 채널 링크의 사진을 읽는다. 메인의 팔로우 컨테이너 바로 왼쪽에 보관 버튼을 배치하며 라이브의 기존 툴팁 바깥 배치도 유지한다. 콘텐츠 교체 및 popstate 시 기존 렌더 예약을 사용한다. 조회 타이머와 저장 키는 추가하지 않았다.

## 검증

- `tests/channel-home-harness.html`의 main 없는 메인 구조에 수정 전 HEAD 코드를 실행하면 `채널 메인에 보관 버튼 없음`으로 실패했다. 같은 구조에서 수정 후 16개 검사를 통과했다.
- 메인 보관·해제, 정확한 채널 이름 저장, 사이드바 반영, 헤더 오삽입 방지, 오프라인 채널 이동, 메인↔라이브 왕복, 전체 메인의 보관 사이드바 유지, 설정 끄기·복원과 캐시 재사용을 확인했다. 네이티브 팔로우 클릭은 0회였다.
- 기존 채널 도구 브라우저 검사 34개 통과. 두 로컬 검사 탭의 warning/error 로그 없음.
- 루트 JavaScript 전체 문법 검사, Node 검사 28개(core/channel-data/quality-bridge/media-background), manifest JSON 파싱 및 git diff --check 통과.

공개 사이트의 실제 구조 조회와 로컬 fixture에서 수정 코드를 실행한 결과다. 설치된 확장의 직접 재로딩이나 사용자 로그인 환경에서의 확인은 수행하지 않았다. 실제 채팅 입력·전송은 수행하지 않았다. 적용하려면 확장을 다시 로드하고 치지직 탭을 새로고침해야 한다.
