# 0.5.0 검증 기록 — 2026-10-28

## 수정과 검증

- 영타 검색: 치지직의 자체 Enter·검색 버튼 핸들러가 폼 제출 보정을 건너뛰는 경로와, 다른 응답을 기다리느라 채널이 표시되지 않는 경로를 0.4.1 코드에서 재현했다. 새 코드는 먼저 끝난 결과를 즉시 표시하고 키·버튼 단계에서 검색어를 보정한다. 회귀 3건이 실패에서 성공으로 바뀌었다.
- 광고 소리: 광고 준비 중 본방의 이전 음소거 상태를 잃는 경우와 광고 SDK가 전체 음소거로 반영하는 경우를 모의 SDK에서 재현했다. 확장이 변경한 광고 영상의 음소거 이벤트만 차단하고 광고 전 상태를 보존한다. 관련 3건이 실패에서 성공으로 바뀌었다.
- 전역 배속: 실제 background 스크립트를 로컬 worker에서 실행하여 0.1배 조절, 1배 복귀, 측정된 60fps 기준 전후 프레임 이동, 입력창·Shadow DOM 입력창 통과, iframe 명령 전달을 확인했다.
- 목록 미리보기: 치지직의 현재 목록 DOM과 공식 auto-play-info 응답, 숲의 현재 `.com` 목록 DOM과 공식 PreviewPlayer 생성 인자를 확인했다. 모의 검사에서 음성 재생 명령, 한 재생만 유지, 다시 우클릭·마우스 나감 종료, Shift+우클릭 원래 메뉴 유지가 통과했다.
- 치지직 실제 공개 미리보기 스트림을 로컬 검증 페이지에서 HLS.js로 재생했다. 853×480, readyState 4, 재생 시간 증가, muted=false 상태와 콘솔 오류 없음이 관측됐다. 이는 설치된 확장의 실제 우클릭 이벤트까지 검증한 것은 아니다.
- 현재 치지직 실제 메뉴의 1080p 원본 60fps 항목을 확인했다. 테스트 브라우저에서 선택 시 사이트의 고화질 확장 설치 안내가 나와 480p가 유지됐다. 고화질 설치·로그인·플랫폼 조건이 없는 것처럼 보고하지 않는다.
- 전체 브라우저 검사 63건, 코어 테스트 4건, JavaScript 구문 검사와 manifest 파싱이 통과했다. 단축키 이전·기본 6행·명시적 빈 목록도 유지됐다.

## 확인하지 않은 범위와 적용

실제 치지직 채팅에 입력하거나 전송하지 않았다. 실제 광고 종료와 숲 미리보기 오디오의 최종 확인, 다양한 사이트·DRM·닫힌 Shadow DOM에서의 배속 적용은 미완료다. FPS를 관측하지 못했을 때와 가변 FPS의 프레임 이동에는 추정 오차가 있을 수 있다.

읽기 전용 브라우저 설정에서 프로젝트 폴더를 참조하는 웨일 개발판이 등록돼 있고 기존 0.3.15 스토어판에는 비활성 사유가 있음을 확인했다. 스토어판이 원인이라고 단정하지 않는다. 설치된 페이지의 실제 코드 버전은 확인하지 못했다. 팝업에 설치 버전·페이지 연결 상태를 추가했다.

브라우저 도구가 확장 관리 페이지 접근을 차단하여 실제 개발판 재로드는 완료하지 못했다. 기존 개발판을 다시 로드하고 해당 탭을 새로고침해야 새 콘텐츠 스크립트와 모든 HTTP/HTTPS 사이트 범위가 적용된다. 브라우저 내부·보호 페이지 제한, 플랫폼의 고화질 설치 조건과 계정 제한은 유지된다. 광고 차단 안내 숨김은 표시만 제어하며 다른 광고 차단기의 설정이나 서버 화질 정책을 바꾸지 않는다.

배포 ZIP·원본 응답·브라우저 검사 JSON·실제 재생 캡처는 Git에서 제외한 `artifacts/`에 있다. HLS.js 1.7.3은 공식 npm 배포본과 라이선스를 함께 포함한다.
