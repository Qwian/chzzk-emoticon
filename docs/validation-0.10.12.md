# 0.10.12 검증 기록 — 2026-11-01

## 변경

- 치지직·숲의 기본 극장모드를 Esc로 해제한다. 입력창·채팅·외부 버튼·shadow 입력창·모달에 포커스가 있어도 동작한다. 활성 상태를 확인하므로 일반 화면의 Esc가 극장모드를 켜지 않는다.
- 유튜브의 큰 극장모드도 Esc로 해제한다. 원래 채팅 iframe은 Esc 요청만 부모에 전달하고, 부모는 같은 출처와 현재 채팅 프레임의 발신 여부를 확인한다. 채팅 DOM과 작성 내용을 유지한다.
- 처리한 Esc의 반복과 대응 keyup을 차단해 중복 전환을 막는다. 실제 전체화면의 Esc는 브라우저 기본 동작에 맡긴다. 넥슨의 F 실제 전체화면 동작은 유지한다.
- 기존 기능 설정을 사용하고 표시 버전을 0.10.12로 맞췄다.

## 검증

- 수정 전 코드로 새 Esc 해제 검사 실패를 재현했다.
- 브라우저 모형 169개 통과: 치지직 동작 20개, 숲 동작 28개, 유튜브 배치 34개, 넥슨 신·구 배치 각 15개, 기존 치지직·숲 단축키 각 21개, 모달 회귀 15개. 페이지 오류 없음.
- 실제 공개 치지직 다시보기에서 F 진입 → Esc 해제로 넓은 화면 false → true → false, fullscreen=false, 페이지 오류 없음 확인.
- 실제 SOOP 공개 오프라인 플레이어에서 같은 스크린모드 전환 확인. 사이트의 `auto play block` 오류가 있었으며, 이전 검증에서 확장 없는 프로필에서도 재현된 오류다. 생방송 재생 검증으로 간주하지 않는다.
- 루트 JavaScript 전체 문법 검사, manifest JSON 파싱, Node 검사 29개 통과.
- 유튜브 실제 로그인 채팅과 사용자 웨일의 최종 적용은 미확인이다. 실제 채팅 입력·전송과 게임 조작은 수행하지 않았다.

모형·실제 사이트 결과 JSON과 배포 ZIP은 Git에서 제외되는 `artifacts/`에 보존한다.
