# 0.10.28 검증 기록 — 2026-11-10

## 재현과 변경

치지직에서 F를 누르면 넓은 화면 대신 전체화면이 자주 열린다는 제보에 대응했다. 기존 코드는 플레이어 바깥의 버튼·링크·`role=button`에 포커스가 있으면 F 처리를 건너뛰었다. 치지직의 기본 전체화면 단축키는 이 상태에서도 실행됐다.

실제 unpacked 0.10.27을 격리 Edge에 로드한 로그아웃 공개 다시보기에서, 플레이어 포커스는 정상적으로 넓은 화면을 전환했다. 같은 페이지의 플레이어 바깥에 진단용 버튼을 추가하고 포커스를 두자 실제 F 키 입력 후 `document.fullscreenElement`가 생겼다. 전후 결과는 `artifacts/f-focus-before-chzzk.json`에 보존했다. 이는 제보와 같은 증상을 일으키는 경로를 확인한 것이며 사용자 웨일의 당시 포커스를 확인한 것은 아니다.

치지직에서는 버튼·링크 포커스에서도 F의 keydown/keyup을 소유하고 넓은 화면 버튼을 실행한다. 확장 메뉴의 shadow DOM 버튼도 포함한다. 입력창·채팅·조합키·IME 조합·보이는 모달 제외, 숲의 기존 포커스 정책 및 Space/M/F11 처리는 유지한다. keypress 누출은 초기 가설이었으며 이번 수정에 추가하지 않았다.

- 루트 JavaScript 23개 문법 검사 및 manifest 0.10.28 파싱 통과.
- Node 검사 45개 통과, 실패·건너뜀 없음.

- 실제 unpacked 0.10.28을 격리 Edge에 로드해 manifest 정상 로드를 확인했다. 로그아웃 공개 다시보기에서 외부 버튼·링크·role 버튼·플레이어 내부 shadow DOM 버튼에 각각 포커스를 두고 F를 네 번씩 입력했다. 16번 모두 일반/넓은 화면이 번갈아 전환됐으며 실제 전체화면 진입은 0회, 페이지 및 확장 실행 예외는 0건이었다. 결과: `artifacts/f-focus-0.10.28.json`.
