개인정보처리방침

최종 수정일: 2026년 9월 1일

치지직 Caps Lock 이모티콘(이하 “확장 프로그램”)은 사용자가 지정한 단축키로 치지직 채팅 입력창에 이모티콘 또는 문자열을 입력할 수 있도록 돕습니다.

처리하는 정보

확장 프로그램은 기능 제공을 위해 다음 정보를 사용자의 브라우저 내부에서 처리할 수 있습니다.

  • 사용자가 지정한 키, 이모티콘 또는 문자열 매핑과 확장 프로그램 활성화 상태
  • 사용자가 선택한 치지직 이모티콘의 코드, 설명 및 이미지 주소
  • 사용자가 입력 진단 기능을 직접 켠 경우 키 코드, 입력 이벤트 유형, 조합 상태, 입력창의 문자 수 등 문제 해결용 이벤트 정보

확장 프로그램은 치지직 계정 정보, 비밀번호, 결제 정보 또는 채팅 메시지 내용을 수집하지 않습니다. 입력 진단 기록에는 입력창의 문자 수가 포함될 수 있으나 입력된 채팅 내용 자체는 저장하지 않습니다.

이용 목적

  • 사용자가 설정한 단축키와 이모티콘 매핑 유지
  • 치지직 채팅 입력창에 사용자가 선택한 이모티콘 또는 문자열 입력
  • 사용자가 직접 활성화한 입력 진단 기능을 통한 문제 확인

저장 및 전송

설정과 진단 기록은 Chrome의 확장 프로그램 로컬 저장소(chrome.storage.local)에만 저장됩니다. 개발자가 운영하는 서버로 전송되지 않으며, 판매되거나 광고 또는 신용도 평가에 사용되지 않습니다. 제3자에게 제공하지 않습니다.

치지직 이모티콘 이미지는 치지직이 제공하는 이미지 주소를 이용해 브라우저에 표시될 수 있습니다. 이는 확장 프로그램 개발자에게 데이터를 전송하는 기능이 아닙니다.

보관 및 삭제

  • 단축키와 이모티콘 매핑은 사용자가 설정에서 변경하거나 삭제할 때까지 보관됩니다.
  • 입력 진단 기록은 최대 300개의 이벤트만 로컬에 보관되며, 확장 프로그램 설정의 “로그 지우기” 기능으로 삭제할 수 있습니다.
  • 확장 프로그램을 제거하면 해당 확장 프로그램의 로컬 저장 데이터도 브라우저에서 제거됩니다.

권한 사용

  • storage: 단축키, 이모티콘 매핑, 활성화 상태 및 선택적으로 생성되는 진단 기록을 로컬에 저장하기 위해 사용합니다.
  • https://chzzk.naver.com/*: 치지직 채팅 입력창을 확인하고 사용자가 선택한 이모티콘을 입력하기 위해 사용합니다. 다른 웹사이트에서는 실행되지 않습니다.

제한적 사용 준수

확장 프로그램의 사용자 데이터 사용은 Chrome 웹 스토어 사용자 데이터 정책 및 제한적 사용 요구사항을 준수합니다. 사용자 데이터는 확장 프로그램의 공개된 단일 목적을 제공하는 데 필요한 범위에서만 사용됩니다.
