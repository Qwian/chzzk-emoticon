# 0.7.2 검증 기록 — 2026-10-29

## 변경

사용자 환경에서 기본 팔로잉 사진 툴팁 안에 작은 영상이 겹쳐 표시된다는 보고에 따라, 0.7.1의 기존 창 재사용·이동 처리를 제거했다. 팔로잉과 보관 모두 동일한 독립 커스텀 플레이어를 사용한다.

- 행에 마우스를 올린 직후부터 기본 사진 툴팁 전체를 숨긴다. 영상은 300ms 대기 후 생성한다.
- 늦게 나타난 치즈 플래터 hover 미리보기도 CSS로 숨기고 재생 시도는 일시 정지한다. 커스텀 플레이어를 외부 창에 넣거나 옮기지 않는다. 직접 고정한 외부 플레이어는 유지한다.
- 커스텀 영상의 소리·100% 음량·초기 최고 화질 요청과 카테고리·공개 시청자 수 표시를 유지한다.
- 마우스 이탈, Esc, 채널 이동, 설정 끄기, 탭 숨김에서 영상과 사진 억제 상태를 정리한다. 외부 툴팁 DOM과 본방 플레이어는 변경하지 않는다.

## 검증

- 루트 JavaScript 문법 검사와 manifest JSON 파싱, git diff --check 통과.
- Node 16개 테스트 통과.
- 로컬 사이드바 26개 검사 통과: 큰 사진이 포함된 툴팁 전체 숨김, 대기 중 억제, 빠른 이탈 복원, 독립 영상 크기, 늦은 외부 창 억제, 숨긴 영상의 play 이벤트 정지, 본방 영상 제외, 고정 창 유지, 음량·화질·메타데이터·취소·설정 동작을 확인했다.
- 치지직·숲 썸네일 우클릭 13개 회귀 검사 통과.
- 미디어/HLS/API는 모사했다. 실제 채팅 입력·전송과 팔로우 상태 변경은 수행하지 않았다.

## 실제 환경 확인

확장 관리 화면의 도구 접근 제한으로 등록된 개발 확장을 직접 다시 로드하지 못한다. 기존 확장 다시 로드와 치지직 F5 후 사용자의 실제 팔로잉 목록에서 사진 없이 커스텀 창 하나만 보이는지 확인해야 한다. 로컬 모사 검증을 실제 방송 재생 검증으로 보고하지 않는다.
