# 0.10.27 검증 기록 — 2026-11-07

따라잡기가 꺼진 상태에서도 호버하면 포인터가 왼쪽 위로 이동하고 원래 위치에 `자동 따라잡기 꺼짐` 박스가 나타난다는 사용자 제보에 대응했다. 이 문구는 플레이어 따라잡기 summary의 기본 `title` 툴팁과 일치했다. 소스에서 같은 title을 사이드바 렌더링마다 1.5초 주기로 다시 쓰는 동작을 확인했다.
