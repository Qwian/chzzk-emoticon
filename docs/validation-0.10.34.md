# 0.10.34 검증 기록 — 2026-11-21

## 결과

사용자 요청은 **처음 방송에 입장할 때 입장 전 최근 채팅 표시**다. 이 기능은 미구현이다. 현재 SOOP 공식 SDK와 생방송 클라이언트에서 과거 메시지를 조회하는 경로를 확보하지 못했다. 조사 범위와 한계는 [조사 기록](soop-prejoin-chat.md)에 남겼다.

0.10.33의 숨김 중 보관 기능은 요청을 해결하지 못한 변경이므로 MAIN 스크립트, manifest 주입, 기능 플래그 연결, 관련 모형·브라우저 검사를 철회했다. `free-chat.js`는 0.10.32와 동일하며 manifest의 런타임 주입 목록도 0.10.32와 같다. 새 채팅 조회 기능을 추가한 버전으로 안내하지 않는다.

## 검증

- 루트 JavaScript 전체 문법 검사, manifest 파싱, `git diff --check` 통과.
- 번들 Node로 기존 테스트 50개 실행·통과. 실패·건너뜀 없음.
- `tests/free-chat-tabs.browser.cjs`: 치지직·SOOP 모두 탭 분리, 새로고침·새 탭, 단축키, 공통 배치 변경, 기능 재시작과 채팅 DOM 교체 검사 통과.
- 격리 Whale에서 실제 unpacked manifest 0.10.34 서비스 워커 로드. SOOP 페이지의 기존 채팅 도구가 설치되고 철회한 MAIN 전역 및 기능 플래그가 없는 것을 확인했다. 확장 출처의 페이지 실행 오류 없음. 임시 프로필 자동 정리 완료. 사용자 Whale의 기존 탭 재로드는 이 검사에 포함하지 않았다.
- 격리 Edge의 치지직 신규 페이지에서 `5101` 요청과 `15101` 응답, 입장 전 시각의 메시지 50개를 확인했다. SOOP 진단 시도는 채팅 소켓에 연결되지 않아 실제 서버의 기록 조회 지원 여부를 입증하는 근거로 사용하지 않았다.
- 실제 채팅 메시지를 입력하거나 전송하지 않았다.

## 패키지와 보존

`tools/package-release.py --clean`으로 37개 런타임 파일의 전체 바이트와 manifest 참조를 검증했다. SHA-256: `d2cc250b8089fbff021444fe3ad9f1cce439315ea7dab5f5bdc238b4ad1ad235`.

현재 0.10.34와 Git으로 재현·대조한 복구용 0.10.32를 보존했다. 철회된 0.10.33이 복구본으로 선택되지 않도록 기존 자동 패키징 경로에 제외 목록을 연결했다. 바이트가 Git 원본과 일치하는 0.10.33 ZIP만 정리했고, 검증 불가 이전 ZIP 33개는 보존했다.

ZIP 총합은 13,139,567 → 12,807,375바이트로 332,192바이트 감소했다. 새 ZIP 생성 전후의 순차이는 -1,405바이트다. 이번 조사의 작은 공식 문서 원본·요약 진단 결과는 재검증 근거로 보존했고, 브라우저 임시 프로필은 종료 후 삭제했다.
