# 0.6.1 검증 기록 — 2026-10-29

## 변경

- 채널 별을 기본 숨김으로 바꾸고 행 hover와 키보드 focus-visible에서만 표시한다. 글자 별을 둥근 선 연결의 SVG로 교체했다. 마우스로 누른 뒤 포커스가 남아도 hover를 벗어나면 숨긴다.
- 즐겨찾기 그룹을 유지하면서 일반 채널은 팔로잉 LIVE, 보관 LIVE, 팔로잉 오프라인, 보관 오프라인 순서로 정렬한다. 같은 그룹 안의 사용자 순서만 적용하며 드래그로 우선순위 그룹을 넘어가지 않는다.
- 치지직·숲의 미리보기 플레이어 음량을 기존 0.5에서 1로 변경했다. contextmenu 가로채기는 확인된 썸네일 영역 안으로 한정한다. 제목·스트리머명에서 우클릭하면 소리를 토글하거나 기본 메뉴를 막지 않는다.
- 위치 이동 뒤의 상태 문구를 ‘자동 따라잡기만 30초 대기’로 명확하게 했다. 대기 동작은 그대로다.

## 확인

0.6.0의 사이드바 별표·보관 버튼·가위 왼쪽 따라잡기 버튼은 사용자가 실제 브라우저에서 세 곳 모두 표시된다고 확인했다.

현재 치지직 전체 방송 페이지의 실제 DOM에서 썸네일은 이미지가 들어 있는 `_thumbnail_...` 링크이고 제목·스트리머 링크는 별개임을 읽어 확인했다. 실제 목록에서 우클릭하거나 채팅에 입력·전송하지 않았다.

- Node 10개 테스트 및 JavaScript 문법·manifest 검사. 라이브/보관/오프라인 우선순위, 그룹 안 순서와 즐겨찾기 우선 유지 검사를 포함한다.
- 채널 UI 로컬 fixture에서 26개 검사 통과. 상태별 순서, 그룹 사이 드래그 차단 및 같은 즐겨찾기 그룹 드래그를 확인했다.
- 로컬 UI의 모든 별 기본 opacity가 0이고 SVG stroke-linejoin이 round임을 확인했다. 키보드 접근 시 별 표시도 확인했다.
- 치지직·숲 미리보기 fixture에서 썸네일 내부·제목·스트리머명의 우클릭 분리, 100% 음량, 종료·복구를 확인했다. 미디어와 숲 PreviewPlayer는 모사했다.

보관 목록과 등록·해제는 로컬 저장소에만 남고 팔로우 API를 호출하지 않는다. 채널 이름·공개 방송 상태 조회는 치지직에 보내므로 일반 요청 기록은 서버에 남을 수 있으나 보관 여부나 목록·로그인 쿠키를 이 조회에 보내지 않는다.

확장 관리 화면은 도구 접근 제한으로 직접 다시 로드하지 못했다. 0.6.1은 확장 다시 로드와 치지직/숲 목록 탭 새로고침 후 적용된다. 새 버전에서의 실제 음량과 로그인한 목록 동작은 아직 사용자 환경에서 재확인하지 않았다.
