# 0.9.2 검증 기록 — 2026-10-29

## 원인과 수정

일부 방송에서 썸네일 우클릭이 미리보기 대신 기본 메뉴를 여는 제보를 확인했다. 현재 공개 치지직 전체 방송 목록에는 썸네일 영역 자체가 `<a class="_thumbnail_…">`인 카드가 있고, 직접 올린 이미지 등은 자동 썸네일의 `/thumbnail/` 경로를 사용하지 않는다.

기존 코드는 `/thumbnail/` 경로 이미지의 상위 영역을 찾거나 라이브 링크 **안쪽**의 thumbnail 요소만 찾았다. 이미지 경로가 다르고 링크 자체가 썸네일인 경우 둘 다 실패해서 contextmenu 이벤트를 가로채지 않았다. 이를 방송의 재생 지원 여부로 판정한 결과는 아니다.

라이브 링크 자체의 thumbnail/thumb 표식도 검사하도록 수정했다. 이미지 탐색도 현재 검사 중인 링크 내부로 한정한다. 제목·스트리머명, 일반 링크와 Shift+우클릭의 기본 메뉴 정책은 유지한다. 재생 요청·로그인 제한·재시도 정책에는 변화가 없다.

## 검증

- 공개 `https://chzzk.naver.com/lives`의 실제 카드 DOM 100개를 읽어 기존·수정 선택자를 비교했다. 기존 썸네일 영역 인식은 86개, 수정 선택자는 100개였다. 이는 DOM 인식 검사이며 실제 HLS 재생 성공률 검사가 아니다.
- 같은 직접 업로드 이미지·썸네일 자체 링크 구조를 로컬에 추가했다. 수정 전에는 미리보기 시작과 배지 SVG의 종료 검사 2개가 실패했다. 수정 후 우클릭 미리보기 17개 검사 모두 통과했다. 실제 재생 정보 요청 대신 응답과 미디어를 모사했다.
- 기존 재시도 16개와 사이드바 소리 미리보기 26개 브라우저 검사 통과. 우클릭 검사 페이지 warning/error 로그 없음.
- Node 28개 통과. 루트 JavaScript 전체 문법 검사, manifest JSON 파싱·content script 참조 파일 존재 확인과 git diff --check 통과.
- 자동 검사 합계 87개 통과. 실제 방송에 메시지를 입력·전송하지 않았다.

설치된 확장을 직접 재로딩하지 않았다. 새 코드는 확장을 다시 로드하고 목록 탭도 새로고침해야 적용된다. 실제 방송 재생 여부는 사이트의 기존 로그인·제한 및 네트워크 상태에 따라 별도로 확인해야 한다.
