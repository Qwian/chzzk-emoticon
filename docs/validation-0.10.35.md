# 0.10.35 검증 기록 — 2026-11-21

영상 확대 조절판도 따라잡기처럼 바깥 클릭으로 닫힌다. 닫을 때 배율·위치는 유지하고 임시 화면 끌기 모드만 해제한다. 패널과 별도의 실행 버튼은 내부로 판단하며, 바깥에서 누른 원래 동작을 막지 않는다.

`player-view-controls.js`에 Shadow DOM의 `composedPath()`를 사용하는 공통 `dismissOutside` 함수를 추가했다. 캡처 단계에서 처리하고 종료 시 리스너를 제거한다. 영상 단독 전체화면에서 비디오로 재지정되는 패널 입력과 드래그 후속 클릭은 별도로 보존한다. 앞으로 유사 설정 패널에 같은 동작과 검증을 적용하도록 `AGENTS.md`에 명시했다.

## 재현 및 검증

- 수정 전 격리 Whale에서 신규 검사 실패: 바깥 클릭으로 패널이 닫히지 않고 이어지는 버튼 클릭의 열림·닫힘 상태가 뒤집혔다.
- 수정 후 치지직·SOOP 모형에서 내부 버튼, 바깥 클릭, 배율 보존, 기존 클릭 동작 유지, 클릭 전파가 차단되는 경우, 버튼 한 번으로 재열기 검사 통과.
- 설치 Whale 엔진의 실제 포인터 입력으로 두 플랫폼의 바깥 클릭 닫기와 내부 조작·재열기 통과. 플레이어 전체화면·영상 단독 전체화면의 바깥 클릭도 배율을 유지한 채 닫힌다. 전체화면 방향 버튼·화면 끌기·슬라이더 회귀 검사 통과.
- `tests/media-zoom.browser.cjs --whale --public`: 모형 검사 235개, 실제 unpacked 확장 0.10.35 서비스 워커 로드, 재생 유지, iframe·팝업·보조키 공유 및 공개 치지직 VOD 검사 통과. 본편 폭 687 → 858.75px(125%) 및 원상복구 확인. 페이지 실행 오류 없음.
- 루트 JavaScript 전체 문법, manifest 파싱, 기존 Node 검사 50개, `git diff --check` 통과. 실패·건너뜀 없음.
- 검사 결과물은 manifest 버전으로 이름을 정하도록 바꿔 이후 실행이 이전 버전 파일을 덮어쓰지 않는다. 격리 브라우저 프로필은 기존 runner의 종료 경로로 자동 삭제한다.
- 사용자 로그인 Whale 탭과 물리 마우스는 직접 조작하지 않았고 실제 채팅도 입력·전송하지 않았다. 사용 중인 확장과 방송 탭에는 다시 로드·새로고침이 필요하다.
