# 0.10.20 검증 기록 — 2026-11-06

## 변경

- 자동으로 계속 당기려는 사용자 의도에 맞춰 30초 자동 중단 자체를 제거했다. v0.10.19에 남았던 직접 타임바·되감기 보호 및 외부 배속 변경의 `heldUntil = now + 30000` 처리를 모두 삭제했다.
- 재생 위치를 보호하려고 추가했던 포인터/키 입력 감지 함수와 핸들러도 제거했다. 자동 따라잡기가 켜져 있으면 직접 되감은 뒤에도 보정하며, 위치를 유지하려면 따라잡기를 끌 수 있다.
- 외부 배속 변경 시 타이머 없이 소유 배속만 해제한다. 기존의 수동 배속 유지 조건은 남아 있으며 일반 재생으로 돌아오면 타이머 없이 보정을 재개한다. 안정/최소 지연 정책과 실제 재생 준비 상태, 버퍼 부족, 일시정지, 탐색 중 보호 및 짧은 중복 이동 제한은 유지한다.
- `player-tools.js`에 `heldUntil`, `30000`, `30초`, `protectManualSeek`, `seekControl`가 남아 있지 않음을 확인했다. 채널 정보 캐시나 팔로잉 갱신의 30초 주기는 별개이며 변경하지 않았다.
