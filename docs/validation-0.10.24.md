# 0.10.24 검증 기록 — 2026-11-07

보관 LIVE를 현재 방송 카테고리 이름순(한국어 로캘)으로 묶어 정렬한다. 현재 공개 메타데이터의 카테고리를 표시와 정렬에 함께 사용하며, 기존 30초 갱신 시 변경도 반영한다. 카테고리 미확인은 보관 LIVE 마지막에 표시한다. 같은 카테고리 안에서는 기존 수동 순서를 적용하며 드래그와 위·아래 버튼도 그 범위를 따른다. 별표 즐겨찾기·팔로잉·오프라인의 기존 우선순위는 유지한다.

- 루트 JavaScript 전체 문법 검사 및 manifest JSON 파싱 통과.
- Node 검사 35개 통과. 카테고리 정렬, 같은 카테고리의 수동 순서, 공백 정규화, 미확인 후순위, 카테고리 변경, 방송 종료 및 별표 우선순위를 포함한다.
- 격리 Edge의 카테고리 모형 9개, 기존 채널 도구 40개, 채널 메인 16개 검사 통과. 페이지 예외 없음.
- 실제 unpacked v0.10.24 로드 및 서비스 워커 버전 확인. 공개 메타데이터와 사이트 DOM을 모형으로 제공한 페이지에서 게임 → TALK → TALK 순서와 확장 실행 예외 없음을 확인했다. 결과: `artifacts/channel-category-0.10.24.json`.
- 브라우저 검사는 모형 데이터에 대한 검사다. 사용자 웨일의 실제 로그인 방송 목록은 검사하지 않았으며 실제 채팅 입력·전송은 하지 않았다.

배포 ZIP은 manifest가 참조하는 스크립트·아이콘과 팝업·문서를 포함하며 모든 압축 항목을 현재 파일과 바이트 단위로 대조했다. 설치된 확장과 열린 치지직 탭을 모두 다시 로드해야 적용된다.
