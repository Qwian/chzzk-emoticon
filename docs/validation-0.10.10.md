# 0.10.10 검증 기록 — 2026-11-01

## 실제 사용자 증거

사용자가 전달한 팝업 상태는 다음과 같다.

```text
확장 0.10.9 · 페이지 0.10.9 연결됨 · 화질 응답 0 / 보정 0 · 실제 1080p · Space 모달로 판단 (↓53/↑53) · 현재 모달로 판단
```

키 down/up은 모두 들어오며 모달 guard가 보조 재생 처리를 막고 있다. 기존 코드는 `dialog[open]` 또는 `role=dialog aria-modal=true`가 문서에 존재하면 CSS 표시 상태와 관계없이 차단했다. 화면에서 닫혀도 DOM이 유지되는 모달이 이 조건에 걸린다. 사용자 탭의 모달 노드 자체는 도구 오류로 직접 조회하지 못했으므로 그 모달을 만든 사이트/확장의 이름까지 단정하지 않는다.

## 수정

- 모달의 화면 크기·위치와 hidden/inert/aria-hidden, visibility, 부모를 포함한 display·opacity·content-visibility를 확인해 실제 표시된 모달만 차단한다.
- 0.10.9의 즉시 실행 변경은 되돌려 원래 네이티브 우선 처리를 사용한다. 0.10.8 광고 판정 변경도 되돌린 상태를 유지한다.
- 실제 입력 횟수·판정 진단은 유지하고 버전을 0.10.10으로 맞췄다.
- 확장 재로드 뒤 이미 열려 있던 유튜브의 쉼표·마침표가 멈춘 증상은 사용자가 유튜브 새로고침으로 복구됐다고 확인했다. 치지직 외의 영상 탭도 새로고침해야 한다는 안내를 명시했다.

## 검증

- 새 모달 회귀 15개 통과. 기존 0.10.9는 숨김 모달·부모·속성·화면 밖 보관 및 닫은 모달 유지 조건 등 10개가 실패했다.
- 기존 치지직 단축키 21개·SOOP 단축키 21개 및 팝업 Space 상태 표시 검사 통과. 검사 페이지의 pageerror 없음.
- 실제 공개 다시보기 `https://chzzk.naver.com/video/15964028`의 네이티브 플레이어에서 숨김 모달을 남기고 네이티브 키 처리를 차단해 비교했다. 0.10.9는 down/up이 모두 수신돼도 current/last=modal이고 재생 상태가 그대로였다. 수정본은 숨김 모달에서 정지, 실제 표시한 모달에서는 상태 유지, 다시 숨기면 재생으로 바뀌었다. 숨김 모달의 current=ready/last=changed와 pageerror 없음도 확인했다. 실패 조건을 검사 코드로 넣은 대조이며 사용자 웨일에서의 최종 작동 확인과 구분한다.
- 루트 JavaScript 전체 문법·manifest JSON 파싱·Node 검사 29개 통과.
- 실제 로그인 채팅 입력·전송 및 게임 창 조작은 수행하지 않았다. 사용자 웨일에서 새 버전 적용 후의 최종 작동 여부는 아직 미확인이다.
