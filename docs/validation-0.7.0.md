# 0.7.0 검증 기록 — 2026-10-29

## 변경

- 팔로잉·보관 LIVE 행을 300ms 이상 hover하면 오른쪽에 소리 미리보기 플레이어를 띄운다. 본방을 보고 있는 페이지에서도 동작하며 음소거 해제·플레이어 음량 100%를 적용한다. 오프라인이나 별·정렬 버튼에서는 시작하지 않는다.
- 한 번에 하나의 목록/사이드바 미리보기만 재생한다. 빠른 이동·행 제거·Esc·닫기·탭 숨김·채널 클릭·페이지 내 이동에서 영상과 네트워크 연결을 정리한다. 마우스를 미리보기 안으로 옮기면 재생을 유지한다.
- 소리 재생이 브라우저에서 거부되면 명시적 재생 버튼을 제공한다. muted 재생으로 바꾸고 소리가 켜졌다고 표시하지 않는다.
- 보관 채널에 카테고리·태그·공개 시청자 수를 표시한다. 공개 수치 표시 플래그가 꺼졌거나 방송이 끝났으면 숫자를 표시하지 않는다.
- 보관 링크는 일반 새로고침 대신 사이트 내 이동을 사용한다. 기본 클릭에만 적용하며 수정 키/가운데 클릭을 가로채지 않는다. URL과 history의 키·인덱스를 갱신하고 popstate를 전달한다.

## 데이터 요청 확인

치지직 공개 `/service/v1/lives` 응답에서 실제 방송 하나를 선택해 다음을 확인했다. 재생 주소나 토큰은 출력·커밋하지 않았다.

- `/service/v1/channels/{id}`: 공개 이름·이미지·방송 중 여부.
- `/service/v2/channels/{id}/live-detail`: 방송 ID·제목·카테고리·태그·시청자 수·공개 표시 플래그.
- 두 API 모두 Origin `https://chzzk.naver.com`에 대해 HTTP 200과 해당 Access-Control-Allow-Origin 응답을 반환한다.

공유 메타데이터 코드는 쿠키 없이 조회하고 30초간 재사용하며 동시 요청은 최대 3개다. 같은 채널을 보는 목록/미리보기 요청은 합친다. hover 요청의 소비자가 사라지면 대기/진행 요청을 취소하되 다른 소비자가 있으면 유지한다. 캐시에는 공개 표시 필드만 남기며 영상 주소·토큰·계정 필드는 남기지 않는다. 재생은 기존 미리보기 API와 포함된 HLS 코드를 사용한다.

- 실제 채팅 입력·전송과 팔로우/해제는 수행하지 않았다.

## 남은 실제 브라우저 확인

도구의 확장 관리 화면 접근 제한으로 사용자의 개발 확장을 직접 다시 로드하지 못했다. 새 버전은 기존 확장 다시 로드와 치지직 탭 새로고침 후 적용된다. 실제 사용자 환경의 소리 자동재생 허용 여부·실제 디코딩/음성 및 사이트 내 이동 결과는 아직 확인하지 못했다. 이 버전의 로컬 검사 통과를 실제 로그인 브라우저의 소리 재생 확인으로 보고하지 않는다.
