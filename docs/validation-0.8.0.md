# 0.8.0 검증 기록 — 2026-10-29

## 미리보기 실패 안내

사용자는 목록 미리보기에서 미지원 안내가 나온 뒤 다시 시도하면 재생된다고 보고했다. 코드에서 숲의 일반 `STATUS_ERROR`를 방송 미지원으로 단정하고, 치지직의 모든 요청·파싱 실패를 미지원 또는 제한으로 묶던 경로를 확인했다. 실제 첫 시도가 간헐적으로 실패하는 원인은 확인하지 못했다.

일반 오류에는 실패 사실만 안내한다. 이전 연결을 정리한 뒤 최대 두 번 자동 재시도하고, 계속 실패하면 직접 다시 시도 버튼을 제공한다. API 요청 캐시를 재사용하지 않는다. 닫기·마우스 이탈·탭 숨김은 예약된 재시도를 취소한다. 숲 플레이어의 세대와 미리보기 요청별로 늦은 결과를 구분한다. 오류 뒤 성공을 중복 보고하지 않는다.

## 자유 배치 채팅

사용자가 제공한 SOOP·치지직 자유 배치 채팅 1.4.0을 바탕으로 `free-chat.js`에 통합했다. 치지직 넓은 화면과 숲 스크린모드의 이동·여덟 방향 크기 조절·배경 농도·원래 배치·숲 도킹 폭·컨트롤 겹침 보정·Alt+Shift+C·화면별 배치 프로필을 유지한다. 프로필은 원본과 같이 화면 해상도와 배율을 기준으로 구분하며 동일한 해상도·배율의 서로 다른 물리 모니터는 구별하지 못한다.

배치는 플랫폼별 확장 로컬 저장소에 저장한다. 기존 채팅 DOM과 입력창을 재생성하거나 옮기지 않는다. 기능 끄기와 사이트 DOM 교체에서는 확장이 만든 요소·클래스·CSS 변수·리스너·observer를 정리한다. 설정을 저장한 자기 이벤트로 입력창이나 도구를 재설치하지 않는다. 기존 스크립트의 `sfc-style`을 감지하면 확장 쪽만 대기하며, 어느 쪽이 먼저 실행되어도 원래 스크립트 요소는 건드리지 않는다. 템퍼몽키 전용 저장소를 직접 읽거나 설정을 끄지 않는다. 기존 배치값은 자동 이전되지 않는다.

## 검증

- 루트 JavaScript 전체 문법 검사, manifest 파싱·참조 파일 존재, git diff --check 통과.
- 기존 Node 25개 검사 통과.
- 자유 배치 로컬 브라우저 120개 검사 통과: 치지직 29개, 숲 30개, 기존 스크립트 먼저 실행한 치지직 30개와 숲 31개. 화면별 저장·복원, 드래그 위치·크기, 농도, 원래 배치·숲 도킹 폭, 컨트롤 겹침, 일반 화면·접힘, 키 반복·IME 제외, 설정 끄기·재개, 기존 스크립트의 늦은 실행, 다른 탭의 저장과 채팅 DOM 교체를 확인했다. 포인터 캡처·화면 정보·저장소를 모사했고 숨긴 검사 탭의 animation frame은 타이머로 구동했다.
- 미리보기 오류·재시도 로컬 16개 검사 통과. 일반 SDK 오류 뒤 재생, 두 번 제한, 취소, 수동 복구, SDK 늦은 준비, 네트워크·HLS 오류, 이전 플레이어의 늦은 오류와 잘못된 미지원 안내가 없는 것을 확인했다.
- 기존 목록 우클릭 13개, 사이드바 26개 회귀 검사 통과.
- 팝업에서 자유 배치 설정과 기존 스크립트 전환 안내가 보이고, 체크를 끄면 저장 성공 상태가 표시됨을 확인했다.
- 정적 서버의 캐시가 이전 스크립트를 재사용하는 것을 확인해 검증 harness의 스크립트 URL을 구분했다. 초기 검사에서 발견한 harness의 썸네일 대상 오류·재시도 대기시간·숨긴 탭 animation frame 조건도 수정했다. 최종 수치는 수정된 harness의 결과다.

## 실제 환경에서 남은 확인

위 검증의 미디어·SDK·저장소·사이트 DOM은 모사했다. 설치된 확장을 직접 다시 로드하거나 실제 로그인한 채팅을 입력·전송하지 않았다. 기존 확장 다시 로드 → 해당 템퍼몽키 자유 배치 스크립트만 끄기 → 치지직·숲 탭 새로고침이 필요하다. 이후 실제 사이트에서 배치와 간헐적 미리보기 복구를 확인해야 한다. 로컬 복구 검사를 실제 방송의 실패 원인 규명이나 재발 방지 검증으로 보고하지 않는다.
