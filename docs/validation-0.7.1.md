# 0.7.1 검증 기록 — 2026-10-29

## 변경과 근거

- 보관 목록과 자체 미리보기는 talk·음악 같은 카테고리와 공개 시청자 수만 표시한다. 방송 해시태그를 표시하거나 메타데이터 캐시에 남기지 않는다.
- 팔로잉 행에 기존 치지직 툴팁이 있으면 그 안에서 재생한다. 같은 채널의 고정하지 않은 치즈 플래터 미리보기 포털이 뒤늦게 나타나면 같은 영상을 옮기고 자체 창을 정리한다. 기존 플레이어는 일시 정지하고 숨기며 종료 시 표시·음량 상태를 복원한다. 다른 확장이 소유한 창은 삭제하지 않는다.
- HLS의 작은 플레이어 크기 제한을 해제하고, manifest에서 가장 높은 해상도(동률이면 비트레이트)를 고른 다음 첫 fragment 로드를 시작한다. 이후 자동 품질 조절은 유지한다. 서버가 제공하지 않는 해상도는 만들지 않는다.
- 현재 공개 치지직 번들의 팔로잉 컴포넌트를 확인했다. 초기 상태와 팔로우 상태·경로 변경, 수동 갱신에 연결되어 있으며 계속 열린 페이지의 주기적 갱신 처리는 없었다. 확장에서 기본 팔로잉 갱신 버튼을 30초마다 누른다. 숨겨진 탭은 중지하며 설정으로 끌 수 있다. 페이지 전체를 새로고침하거나 팔로우 상태를 변경하지 않는다. 서버 반영 시간은 별도다.

## 검증

- 루트 JavaScript 전체 문법 검사, manifest JSON 파싱, git diff --check 통과.
- Node 16개 테스트 통과. 공개 메타데이터에 카테고리·시청자 수를 남기고 해시태그·재생 주소·계정 필드를 제외하는지 확인했다.
- 브라우저 16개 검사 묶음 통과(상세 130개 및 단축키/팝업 5개 결과). 기존 채팅 단축키·검색·광고·화질·속도·썸네일 우클릭 회귀 검사를 포함한다.
- 미리보기 20개 검사: 기존 툴팁 재사용, 늦게 뜬 포털로 재생 중인 영상 이동, 중복 플레이어 방지, 음량 100%, 최고 품질 선택 후 로드, 카테고리만 표시, 자동재생 거부와 명시적 버튼, 취소·정리를 확인했다. 미디어와 HLS는 모사했다.
- 채널 목록 34개 검사: 기존 정렬·보관 이동을 유지하며 30초 갱신 시 방송 시작/종료와 정렬 반영, 숨김 중 중지, 복귀 갱신, 설정 끄기를 확인했다. 시간과 서버 응답은 모사했다.
- 실제 채팅 입력·전송과 팔로우/해제는 수행하지 않았다.

## 실제 환경 확인 한계

도구에서 확장 관리 화면 접근이 제한되어 등록된 개발 확장을 직접 다시 로드하지 못한다. 사용자 브라우저의 실제 소리·화질·다른 확장과의 동작은 기존 확장 다시 로드와 치지직 F5 후 확인해야 한다. 로컬 모사 검사 통과를 실제 방송 재생 검증으로 간주하지 않는다.
