# 0.4.0 검증 기록 — 2026-10-28

## 확인한 범위

- JavaScript 6개 파일의 Node 구문 검사, manifest JSON 파싱, `git diff --check` 통과.
- `tests/core.test.cjs` 4개 테스트 통과: 두벌식 조합, 버퍼 범위와 빈 구간, 보정 속도·수동 따라잡기, 채널 경로·설정 검증.
- 브라우저 모의 테스트 23개 검사 통과: 입력 회귀 5개, 문자 매핑 6개, 검색·즐겨찾기·플레이어 10개, 기존 직접 삽입·IME harness 각 1개.
- 팝업에서 8배속 저장, 긴 목록 스크롤, 이전 매핑 2행 이전 및 폐기된 자동 전송 옵션 제거, 새 설치 기본 6행, 명시적 빈 목록 0행 유지를 확인.
- 이전 브리지로 Enter 직후 늦은 조합 입력이 모의 문장·이모티콘을 복원하는 경로를 재현했고, 수정한 브리지에서는 복원되지 않음을 확인.
- 치지직 공개 페이지와 공개 웹 스크립트에서 검색 URL, 본방 영상 클래스, 광고 전용 컨테이너를 읽기 전용으로 확인.

## 실제 서비스에서 확인하지 않은 범위

실제 치지직 채팅에는 입력하거나 전송하지 않았다. 로그인한 채팅에서의 최종 입력 결과는 사용자 확인이 필요하다. Enter를 가로채어 전송하거나 입력창을 임의로 비우는 기능은 없다.

브라우저 도구가 확장 관리 페이지 접근을 보안 정책으로 차단하여, 설치된 확장 재로드와 실제 확장 로딩은 확인하지 못했다. 소스 폴더를 사용하는 브라우저에서 확장과 치지직 탭을 새로고침해야 한다.

실제 광고 중 화면·소리 복원, 배속에 따른 실제 대기시간 감소, 장시간 라이브의 끊김 감소와 실제 송출 지연은 미측정이다. 모의 테스트의 성공을 이 항목의 검증으로 해석하지 않는다. 별도 본방 오디오가 없거나 광고 SDK iframe 내부에만 영상이 있는 유형은 지원하지 않는다.

배포 ZIP, 모의 브라우저 결과 JSON과 설정 화면 캡처는 Git에 포함되지 않는 `artifacts/`에 저장한다.
