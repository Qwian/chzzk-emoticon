# 0.8.2 검증 기록 — 2026-10-29

## 변경

- 따라잡기 summary는 마우스와 포커스가 모두 없을 때도 불투명도가 1이었다. 기본 opacity를 .35로 바꾸고 hover 또는 focus-visible에서만 1로 표시한다. 마우스 pointerdown의 기본 포커스 동작을 막되 details 열기·닫기와 키보드 조작을 유지한다. 설정 패널에는 흐림을 적용하지 않는다.
- 영상 위 배속 안내를 왼쪽 위에 표시하고 가로·세로 여백을 동일하게 계산한다. 영상 크기에 따라 글자를 18~36px로 키웠다. 작은 영상·일부만 보이는 영상은 뷰포트 안으로 보정하고 스크롤·resize·fullscreenchange에 대응한다. manual popover를 사용해 영상 자체의 전체화면에서도 표시하며 클릭·포커스는 가로채지 않는다.
- `/`는 1배속과 직전 배속을 탭별로 전환한다. iframe만 있는 상위 프레임에서도 보고된 실제 영상 배속을 기억한다. 빠른 두 번 입력을 직렬 처리하고, 길게 누르는 키 반복은 무시한다. 수동 증감 후의 최근 배속도 반영하며 원래 1배속이면 다른 이력이 없을 때 1배속을 유지한다. 값은 기존 탭 상태와 같이 서비스 워커 메모리에서 관리한다.

## 검증

- 루트 JavaScript 문법 검사, manifest JSON 파싱·참조 파일 존재, git diff --check 통과.
- Node 28개 검사 통과. 기존 25개와 직전 배속·탭 구분·연속 전환·증감 이후 복원·iframe의 1.75배 복원 3개를 포함한다.
- 기존 채널 도구 브라우저 34개 검사 통과.
- 배속·프레임 이동 브라우저 26개 검사 통과. 좌상단 동일 여백·큰 글자·작은 영상의 경계 보정·입력 방해 없음·슬래시 복원·키 반복·기존 배속 및 프레임 이동을 확인했다.
- 연결 해제의 키 입력 경로와 비동기 거부 2개 시나리오, 14개 검사 통과. 타이머·리스트너·프레임 수집·표시를 정리하는 기존 동작을 확인했다.
- 로컬 플레이어에서 실제 마우스 클릭과 키보드 입력으로 따라잡기 버튼을 확인했다. 평상시 opacity .35, hover 1, 마우스 클릭 후 summary 포커스 없음, 이탈 후 .35, 키보드 focus-visible 유지와 Space 토글을 확인했다. 패널 opacity는 1이었다.
- 로컬 영상의 큰 안내를 시각 확인했다. 640×360 영상에서는 글자 35.2px와 좌·상단 각각 16px, 플레이어 전체화면과 영상 자체의 전체화면에서는 글자 36px와 각각 24px를 확인했다. 두 전체화면 모드에서 popover가 표시됐다. 실제 방송 재생·채팅 입력·전송은 수행하지 않았다.

manual popover의 상위 표시 동작은 [Popover API 문서](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API/Using)를 참고했다. 미디어와 확장 API는 로컬에서 모사했고 설치된 확장의 직접 재로딩 및 실제 사이트 검증은 남아 있다. 확장 다시 로드 후 사용 중인 영상 탭도 새로고침해야 한다.
