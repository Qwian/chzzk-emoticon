# 0.10.38 자유 배치 채팅 수명 관리 재수정 — 2026-11-22

## 이전 수정에서 빠진 경로

사용자가 0.10.37 이후에도 오류가 계속된다고 보고했다. 이를 이전 오류 기록으로 추정해 종료한 응답은 충분한 해결이 아니었다. 이번에는 현재 코드를 기준으로 해제·재진입 경계를 다시 검사했다.

- 0.10.37 코드에서 레이아웃 측정 콜백이 컨트롤러를 해제하면 `applyDockWidth`가 공유 `mount`를 다시 읽어 `Cannot read properties of null (reading 'dockHandle')`가 발생하는 경로를 재현했다. 보고된 `videoMain`과 동일한 문구를 이 추가 경로에서 재현한 것은 아니며, 살아 있는 배치가 사라진 뒤 공유 참조를 읽는 같은 유형의 결함이다.
- 생성 중 첫 모니터 프로필 저장이 동기적으로 실패하면, 전역 stop이 실행될 때 아직 `controller`가 할당되지 않아 생성된 도구가 뒤늦게 남았다. `tests/free-chat-tabs.browser.cjs --baseline`은 0.10.37 Git 코드를 가상 응답으로 읽어 이 경로에서 도구 3개가 남는 실패를 재현한다. 작업 트리의 소스를 교체하지 않는다.
- 컨트롤 배치 함수 안에서 해제하는 경우와 정리 중 다시 정리에 진입하는 경우도 회귀 검사에 추가했다.

## 수정

렌더링·폭 계산·컨트롤 배치·드래그 시작은 한 번 잡은 배치 객체를 사용한다. 외부 측정이나 배치 작업 뒤에는 그 객체가 여전히 현재 배치인지 검사한다. 공유 참조가 해제되거나 다른 배치로 교체됐으면 나머지 작업을 종료한다.

정리는 기존 배치를 로컬에 잡고 공유 소유권을 먼저 비운 뒤 이벤트 해제·포인터 해제·DOM 정리를 수행한다. 콜백이 다시 진입해도 같은 배치를 중복 정리하지 않는다. 컨트롤러 생성 중 전역 종료가 발생했을 때도 반환된 컨트롤러를 즉시 정리한다.

## 검증

- 루트 JavaScript 전체 문법 검사, 브라우저 검사기 문법 검사, manifest 0.10.38 파싱과 git diff --check 통과.
- 자동 테스트 57개 실행·통과, 실패·건너뜀 없음.
- `tests/free-chat-tabs.browser.cjs`: 치지직·SOOP 모두 생성 중 실패, 측정 중 해제, 컨트롤 배치 중 해제, 정리 중 재진입, resize·pointerdown 중 저장 오류에서 예외·도구 재생성 없음, 원래 작성 문장 보존. 기존 탭 분리·새로고침·배치·단축키·DOM 교체 검사도 통과.
- `tests/free-chat-invalidation.browser.cjs`: 격리 Whale에 실제 unpacked 확장을 로드하고, runtime.reload로 실제 확장 API를 무효화한 뒤 화면 크기 변경. 치지직·SOOP 모형 페이지에서 예외 없이 정리되고 원래 입력창과 문장 유지.
- 같은 검사기에 보고된 주소 `https://chzzk.naver.com/live/8a933cb3a86c52aadb2483aa4eed72aa`를 전달해 실제 페이지에서도 채팅 도구가 설치된 것을 확인한 뒤 무효화·화면 변경을 실행했다. free-chat 출처 예외 0개. 이 격리 페이지에는 채팅 영역이 있었지만 영상 플레이어·입력창이 생성되지 않았으므로, 로그인 상태의 영상 재생·작성창까지 검증했다고 주장하지 않는다. 결과: `artifacts/free-chat-invalidation-0.10.38.json`.
- 실제 채팅을 입력·전송하지 않았다. 게임 창을 조작하지 않았다. 테스트 프로필은 종료 후 경로를 검증하여 자동 정리했다.
- 사용자 Whale 제어 연결은 새 세션으로 초기화해도 창 바인딩에 실패했다. 사용자 프로필 자체의 확장 재로드·현재 탭 검증은 수행하지 못했으며, 위 실행 결과는 격리 프로필 결과다.
